# 15 主题系统

## 1. 范围

管：默认皮肤「现代墨白」、用户自配主题色、主题包格式、安装/卸载/预览、三套壳如何套主题、安全边界。  
不管：主题市场账号、付费主题、主题里跑 JavaScript。

已锁定：

- 出厂主题 = **现代墨白**（见 [14](./14-UI规范与方案.md) 方案 E、[预览](./ui-preview.html)）
- 明暗默认 = **跟随系统**
- **主题色（accent）用户可配**，不必为了换一个颜色去装整包
- **支持安装主题**：用户能按文档自己做包、导入就用

---

## 2. 对象与状态机

三层，从下到上覆盖：

```
1. 出厂基础 token（代码内置，保证永远能渲染）
2. 当前安装的主题包（改色板、圆角、字体栈、可选额外 CSS）
3. 用户覆盖（accent、appearance=light|dark|system）
```

计算后的结果叫 **ResolvedTheme**，只含 CSS 变量，注入应用根节点（默认 `:root`）；Tailwind CSS 与 shadcn/ui 只消费这些变量，不维护第二份主题状态。

### 2.1 ThemePackage

| 字段 | 说明 |
|---|---|
| id | `^[a-z][a-z0-9-]{1,63}$`，实例内唯一 |
| name / description / author / homepage | 展示用 |
| version | semver |
| builtin | 出厂不可卸载 |
| modes | 必须含 `light` 与 `dark`（可做成同一套变量两份） |
| tokens.light / tokens.dark | 语义色 |
| radius / font.ui / font.mono / font.title | 可选 |
| extra.css | 可选，**纯 CSS**，选择器白名单 |
| preview.png | 可选，设置页缩略图 |

### 2.2 偏好落点

| 谁 | 配什么 |
|---|---|
| 实例 | 访客默认主题、是否允许用户装主题、是否允许用户改 accent |
| 用户 | 主题 id、accent、appearance |
| 文档站（笔记本） | 可选覆盖主题 id + accent，只影响 `/s/...` 访客 |
| 分享页 | 跟实例默认；不跟作者私人霓虹主题，避免泄漏「作者品味」当指纹。一期不单独配 |

工作区不单独做主题（避免一家三口三套壳）。要个性：用户自己的 App 壳跟自己走。

### 2.3 状态

```
主题包: installed → disabled → uninstalled
用户: 选用某 installed 包；包被卸后回退 builtin
```

## 3. 交互

### 3.1 设置 → 外观

- 明暗：跟随系统 / 浅 / 深
- 主题色：色板预设（黑、白、灰、蓝、青、朱）+ 自定义 hex
- 对比度即时预览（小三栏缩略）
- 「重置为主题默认色」

改 accent **立刻生效**，不必装包。

### 3.2 设置 → 主题

卡片列表：缩略图、名称、作者、正在使用。  
操作：预览（临时 30s 或关模态还原）、启用、卸载（builtin 无）。  
「导入主题」：上传 `.zip` 或选 `data/themes/` 已放的目录。校验失败给人话错误。  
「导出当前」：把当前 token + 用户 accent 打成包，方便改完再分发。  
「制作说明」链到 [主题开发手册](../主题开发手册.md)。

### 3.3 实例后台

- 默认主题（访客广场、未登录文档站）
- 开关：允许成员安装主题 / 只允许用管理员装过的包
- 家庭建议：管理员代装，成员只选

### 3.4 文档站

笔记本发布设置可「使用实例默认」或指定已安装主题 + 独立 accent。不让访客再装主题。

## 4. 业务规则

1. **主题不能含 JS、不能含 `@import url` 外链、不能含 `expression()`。** 失败则拒装。
2. extra.css 选择器只允许：`:root`、`[data-theme]`、`.app` `.site` `.feed` `.markdown` 及其后代；禁止 `html` 改 `display`、禁止 `position:fixed` 全屏盖层。
3. 必须同时提供 light/dark，缺一面用另一面加自动反相？**不准自动反相。** 缺则拒装。
4. 必填语义 token 缺一不可（见 5.1），否则拒装。
5. 用户 accent 覆盖 `--accent` `--accent-fg` `--accent-soft`（soft 由 accent 按算法生成，用户不必填）。
6. 对比度：正文 `fg` 对 `bg` 至少 7:1 建议、4.5:1 硬限。校验失败仍可装，设置页打警告「阅读对比不足」。
7. 卸载正在使用的包：所有用它的用户回退 `mono-modern`，通知一条。
8. 同 id 再导入 = 升级（比版本号），可回滚到上一份 zip（只留 1 个备份）。
9. 公开页（广场未登录、分享）只用实例主题 + 实例 accent，避免「未登录闪一下用户粉红主题」。
10. 已登录 App / 圈子 / 设置：用用户主题。
11. 文档站：笔记本配置 > 实例默认。作者自己进「编辑原文」仍是用户主题。

## 5. 算法与格式

### 5.1 语义 token（主题必填）

```
bg            页面底
bg-subtle     侧栏 / 次级底
bg-muted      代码栏、输入底
fg            主文字
fg-muted      次文字
border        分割线
accent        主题色（可被用户覆盖）
accent-fg     铺在 accent 上的字（黑或白，按亮度自动）
accent-soft   选中浅底
good / danger / warning
wiki          默认同 accent
wiki-unresolved  默认同 fg-muted
radius        例如 8px
font-ui / font-mono / font-title
```

组件只引用语义名，禁止写死 `#2563EB`。Tailwind/shadcn 的 `background`、`foreground`、`primary`、`primary-foreground`、`muted`、`muted-foreground`、`border`、`ring` 等命名在样式入口桥接到上述变量；完整映射与组件约束见 [14-UI规范与方案](./14-UI规范与方案.md) 第 8–15 节。

### 5.2 用户 accent → 派生

```
accent = user.accent || theme.accent
accent-fg = relativeLuminance(accent) > 0.55 ? #0A0A0A : #FAFAFA
accent-soft = mix(accent, bg, 88%)
```

黑作为 accent 时 soft = 浅灰选中底，不要真用 12% 黑铺一整行（现代墨白预览里是实心黑条，这是主题自己的 `--nav-active` 可选手）。  
出厂主题另给可选 `nav-active-style: solid | soft`。默认 solid（预览那种黑底反白）。

### 5.3 包目录

```
my-theme/
  theme.json
  preview.png          # 可选 640x360
  extra.css            # 可选
```

zip 根必须直接是这些文件，或唯一一层目录。

`theme.json` 最小例子：

      "bg-subtle": "#141414",

字体栈只允许系统字体或主题包 `fonts/` 下的 woff2（安装时拷到静态目录）。禁止主题拉 Google Fonts。

### 5.4 extra.css 消毒

1. 用可靠 CSS 解析器，不是正则
2. 丢掉 `@import`、`url(` 除 `data:` 与同源 `/theme-assets/{id}/`
3. 丢掉 `*` 选择器改 `body` 背景图以外的布局属性（position/z-index/transform 白名单外）
4. 体积 ≤ 64KB

做不到解析就一期 **禁止 extra.css**，只开放 json token。推荐一期先只做 json，extra.css 标「二期但格式先公开」。

**拍板：一期只支持 `theme.json` token。** `extra.css` / 自定义字体文件格式写进文档当二期，避免 XSS。用户已经能靠换全套色做出完全不同的气质。

### 5.5 解析顺序

```
base builtin tokens
  ← merge theme.tokens[mode]
  ← overlay user.accent 派生
  → 写成 style="--bg: ...; --fg: ..."
```

`mode` = user.appearance==system ? matchMedia : user.appearance

## 7. 制作指南（给用户看的短版）

1. 复制出厂 `mono-modern` 的 json  
2. 改 `id`（别和别人撞）和两套颜色  
3. 打成 zip 上传，或丢进服务器 `DATA_DIR/themes/你的id/`  
4. 在设置里启用  
5. 自己的主题色仍可在启用后再调，只覆盖 accent  

不要写 JS。不要外链字体。必须有浅色和深色。
