# 07 分享链接与文档站

## 1. 范围

管：多条分享链接、密码与有效期、整本/目录/单篇/单节/附件分享、`/shares` 管理、笔记本发布为实时文档站、两通道生命周期独立、公开页渲染。  
不管：评论纠错细节（08）、自定义域名（二期）。

---

## 2. 对象与状态机

### 2.1 ShareLink

| 字段 | 说明 |
|---|---|
| token | 32 字节 url-safe，**明文只作 URL，库内可存明文 token（它就是能力凭据）或只存哈希**。建议只存哈希，URL 发给创建者后自行保管；管理页只能「复制」若选择存明文。**一期为了「管理页复制链接」，存 token 明文，备份需一并视为机密。** |
| target_type | `note` / `heading` / `folder` / `attachment` / `notebook` |
| target_id | note/folder/attachment/notebook id |
| heading_anchor | type=heading 时 |
| password_hash | 可空 |
| expires_at | 可空 |
| allow_robots | 默认 false |
| show_backlinks | 默认 false |
| comments_enabled | 默认 true |
| corrections_enabled | 默认 false |
| created_by, created_at | |
| status | `active` / `revoked` |

有效判定：`status==active AND (expires_at is null OR now < expires_at) AND 目标未 purge`。  
目标仅在回收站：视为无效，对外统一「不存在或已失效」。恢复后若链接仍 active 且未到期，自动恢复可访问。

一篇笔记 / 一个目录 / 一个附件 / 一本笔记本可有多条链接。互不影响。  
整本分享 ≠ 文档站：分享链接带密码、有效期、可多条可撤销，投影本里**全部未删除**的笔记（不看 `published`）；文档站走 `/s/...`，只给 Admin/Owner 发布，且只展示 `published=true` 的篇。

### 2.2 Site（挂在 Notebook 上）

| 字段 | 说明 |
|---|---|
| published | 整本是否上线 |
| slug | `/s/{ws_slug}/{nb_slug}` |
| title, logo, theme_color, home_note_id | |
| comments_enabled / corrections_enabled / guest_enabled | |
| allow_robots | 默认 false |

文档站是**实时投影**：读请求时查现笔记，没有单独发布快照表。

## 3. 交互

### 3.1 从笔记创建分享

属性面板或分享按钮 → 类型（整篇 / 当前标题节 / 某附件）→ 密码可选 → 有效期可选（7 天/30 天/自定义/永不过期）→ 生成 → 展示 URL 一次可复制。  
「再生成一条」不是覆盖。

目录：在中栏目录右键「分享此目录」。说明文案：「之后在这个目录下新建的笔记也会出现在此链接里。」  
笔记本：左栏笔记本右键，或中栏本操作菜单「分享这个笔记本」。说明文案：「之后在这个本里新建的笔记也会出现。这和发布文档站不同：这里不看是否已发布。」

### 3.2 `/shares`

表格：对象面包屑、类型、是否有密码、到期、状态、创建时间。  
操作：复制、改密码（空=取消密码）、续期、取消。不回显旧密码。  
工作区设置「本区分享」：Admin/Owner 看全部，可取消别人的。

### 3.3 打开 `/p/{token}`

1. token 无效/取消/过期/目标 trash：同一 404 页。
2. 有密码：先密码表单，session 记 `share_ok:{token}`（浏览器会话）。错密限流。
3. 整篇：干净阅读皮肤，闭集 Markdown，双链按 04 公开规则。
4. 单节：只渲染该 heading 到下一同级/更高级 heading 之前。
5. 目录：左侧只读树（实时子树，不含其他目录），右侧读笔记。
6. 整本：左侧只读树（本内全部未删除的目录与笔记，含根上的篇），右侧读笔记。
7. 附件：下载或图片预览，不列同笔记其他附件。
8. 已登录且 `can_edit`：顶栏「编辑原文」。

`X-Robots-Tag: noindex` 当 `allow_robots=false`。

### 3.4 发布文档站

笔记本设置「发布为文档站」仅 Admin/Owner。填站名、首页笔记（须 published）、开关。打开 `published=true` 立即 `/s/...` 可访问。  
导航 = 目录树过滤掉 `published=false` 与 trash。源笔记一保存，公开页下一请求即新内容。  
下线：`published=false`，`/s/...` 404。已有 ShareLink 不动。

## 4. 业务规则

1. 创建权限见 02 `can_create_share`。Viewer 无。
2. 打开分享**不要求**是成员，不走工作区 ACL。密码是唯一额外门闩。
3. 文档站与分享互不级联作废。
4. `published=false` 的篇、以及 `moderation_status` 不是 `none` 的篇：不在站内导航与站内搜索；若有单独 ShareLink 仍可经分享打开。审核中的公开意图见 [18](./18-内容审核.md)。
5. 目录 / 整本分享的子树实时变化，含之后新建。不想这样就分享单篇或先建一个只放要发的目录。
6. 取消分享不可逆（可再新建另一条新 token）。
7. 轮换 = revoked 旧的 + 新建同配置。
8. 私有笔记本也可以出分享（创建者自己发账本某一页给会计）。不因此改变 ACL。
9. 附件 URL 必须带 token，禁止 `/files/{note_id}/x.png` 无鉴权。
10. 分享页无 AI、无 MCP、无工作区树、无其他笔记本入口。

## 5. 算法

### 5.1 访问

```
link = by_token_hash_or_plain
if not effective(link): NOT_FOUND
if link.password_hash and not session_ok:
    return password_form
if target.trashed or purged: NOT_FOUND
render(target)
```

heading 切片：

```
从 '# 标题' 匹配 slug/原文
直到下一个同级或更高级 heading
保留该段内图片（仍走带 token 的附件 URL）
```

### 5.2 目录 / 整本子树

```
目录：活着的子 folder + 子 note（含后来新建；不含本根上、目录外的篇）
整本：该 notebook 下全部活着的 folder + note（含 folder_id 为空的根篇，含后来新建）
都不检查 published（分享 ≠ 文档站）
深度与 03 相同
笔记本进回收站：整本链接对外统一「不存在或已失效」；恢复后若链接仍 active 且未到期，自动恢复
```

### 5.3 站内 URL

```
/s/{ws}/{nb}/                    首页笔记
/s/{ws}/{nb}/{note_id}           用 id 防改标题碎链
可选同时支持 /s/.../path/title  301 到 id
```

### 5.4 robots

站点或链接 `allow_robots=false`：`noindex, nofollow`。站内搜索也不要把未允许的分享页收录进公开 sitemap。一期可不做 sitemap。
