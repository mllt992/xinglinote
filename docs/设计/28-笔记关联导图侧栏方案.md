# 笔记关联导图侧栏方案（#85，仅方案，尚未实现）

## 阅读流程

沿用现有笔记关联导图查询及笔记本 ACL，在笔记右栏列出可读取的关联导图与画板，展示名称、类型、所属笔记本。点击后仍停留在当前笔记 URL，在同页右侧打开只读查看面板。默认先适应画布，可缩放、平移及回到中心；编辑图仍使用独立编辑器，通过明确的「打开编辑器」动作进入。

笔记正文不卸载、不重建，保留阅读滚动、编辑器 selection 和未保存内容。右侧面板内部独立滚动，不抢正文键盘快捷键；只有面板取得焦点时响应图内操作。打开与关闭时不调用全局 scrollIntoView；关闭后将焦点还给原导图入口，保持原阅读位置。

## 多图和关闭

首次点击直接打开该图，多张关联图在面板顶部用下拉列表切换，不叠加多个渲染器。明确提供关闭按钮、Esc（面板聚焦且无子弹窗时）及关联列表返回。关闭只销毁查看器，不修改关联关系或图内容；重复点击当前图聚焦已有面板。切换笔记、账号或工作区立即清空当前图并中断加载，旧响应按请求代次丢弃。

## 权限和失败

关联列表与图内容分别由现有服务端 ACL 校验，不根据笔记可读权限推断导图可读。列表不泄漏无权图的标题或存在性；请求期间权限撤销则清空图，显示「当前无法查看」并可重试。回收站、已删除和失效关联不自动删除原关系，也不在此方案做权限拓展。渲染继续复用已清洗的导图格式，画板使用既有 iframe origin 校验和只读模式。

## 桌面和窄屏

桌面面板宽度约 420px，可在合理范围拖动，但正文保持最小阅读宽度；保存宽度是设备级偏好，不包含图数据。空间不足时（建议小于 1024px）改为同页抽屉，手机用底部或全屏查看面板。抽屉锁定背景交互并保存正文滚动，关闭恢复原位置与焦点；不跳转路由。每次仅加载一张图，懒加载渲染库，关闭释放事件、观察器和 iframe。

## 后续实施验收

- 阅读中开图、缩放、换图、关闭后正文位置及未保存编辑不变。
- 多图切换、快速重复点击、慢响应、关闭后返回均不显示过期内容。
- 无权限、权限撤销、工作区/账号切换和已删除关联不泄漏内容。
- 375px、平板、桌面和键盘可访问性，以及浅深色只读查看均通过。
