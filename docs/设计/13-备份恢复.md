# 13 备份与恢复

## 1. 范围

管：实例备份、工作区备份、S3/WebDAV 目标、周期与保留、加密与校验、预览、整库恢复、按路径捞单篇。  
不管：S3 当主盘、多机热同步。

---

## 2. 对象与状态机

### 2.1 BackupTarget

| 字段 | 说明 |
|---|---|
| scope | `instance` / `workspace` |
| type | `s3` / `webdav` |
| endpoint 配置 | S3：endpoint、bucket、region、access_key、secret；WebDAV：url、user、password |
| prefix | |
| encryption_enabled | 备份包加密。密钥由管理员粘贴，**只存密钥指纹，加密密钥本身用实例主密钥封装或每次让管理员输入**。一期：设置时输入 passphrase，派生密钥，存 KDF 盐 + 校验，不把 passphrase 明文落盘。 |
| schedule | manual / daily / weekly |
| retain_daily / retain_weekly | 默认 7 / 4 |
| enabled | |

凭证加密存（应用级），**导出的备份包内不得再放这些凭证明文。**

### 2.2 BackupJob

`pending` → `running` → `success` / `failed`  
记录：started、bytes、checksum_sha256、remote_path、error。

### 2.3 包内容

**实例包**

- 用户（含 password_hash、不含 session）
- InstanceSettings（SMTP 密码按「机密字段」另册或同样进加密包）
- 注册码哈希与元数据，不含已展示过的明文码
- 广场 Post、Like、广场评论
- **不含** 任何 MCP secret、用户/工作区 AI api_key 明文

**工作区包**

- 成员与角色、笔记本 ACL
- 全部 md、附件、版本、回收站
- 圈子 Post、本区评论纠错
- Site 配置、ShareLink（token 视为机密，仅加密包可含）
- 标签、树、TitleIndex 可重建，但为恢复速度可带一份 dump
- 不含 MCP secret、AI key

## 3. 交互

### 3.1 配置

实例后台 / 工作区设置 → 备份：加目标、测连接（写一个小文件再删）、选周期、开加密、手动「立即备份」。

### 3.2 历史

列表：时间、大小、校验、状态。操作：预览（列文件树，不下载体）、下载到浏览器（Owner）、恢复。

### 3.3 恢复

两步：选包 → 选「整区覆盖」或「捞路径」。  
整区：输入工作区名/「确认覆盖」，冻结写入，解包，重建索引，解冻。  
捞单篇：选路径，若现网撞 id 则新 id 并提示。  
恢复进行中全员只读横幅。

---

## 4. 业务规则

1. 备份失败发站内信给 Owner/实例管理员。
2. 保留：超期包删除远端。删除前至少留 1 个成功包。
3. checksum 不匹配禁止恢复。
4. 加密包无 passphrase 不能预览内容。
5. 恢复不重放 MCP 钥匙、不重写 AI key。用户需重配。界面恢复完成后列出「需要重新配置的项」。
6. 实例恢复是灾难操作，仅实例管理员，且不能在线随便点——须确认短语。
7. 工作区备份不含其他区数据。
8. 同一目标同时只跑一个 job。

## 5. 算法

### 5.1 打包

```
snapshot DB consistent rows (transaction or dump)
copy files by note_id list
tar/zip → optional encrypt(age/libsodium, passphrase KDF)
sha256
upload to S3/WebDAV
verify listing + optional download head hash
apply retention
```

### 5.2 保留

```
keep last N daily
keep last M weekly (每周最新一份)
delete others on that target/prefix
```

### 5.3 整区恢复

```
frozen=true
replace workspace rows + files
rebuild TitleIndex, search, chunks
emit 批量 NoteUpserted 或直接重建
frozen=false
```

双链：有 Link 表 dump 则直接灌；否则全量重解析。

### 5.4 单篇捞回

解开单文件 + 附件。若 id 冲突：新 UUID，源码 `[[ ]]` 不改（仍是标题）。告知用户。

## 6. 与其他功能的关联

| 方向 | 关系 |
|---|---|
| ← 全模块 | 包内容清单以各文档「进备份吗」为准 |
| ← 11、10 | 明文钥匙永不进包 |
| ← 07 | 分享 token 只进加密工作区包 |
| ← 12 | 回收站一并备；purge 后只能靠包 |
| → 01 | SMTP 失败不影响备份本身 |

机密分级：

| 数据 | 策略 |
|---|---|
| 笔记正文 | 进包 |
| 分享 token | 仅加密包 |
| 用户密码哈希 | 仅加密实例包 |
| MCP secret / AI api_key | **永不进包** |
| 注册码明文 | 永不进包（只有哈希） |
