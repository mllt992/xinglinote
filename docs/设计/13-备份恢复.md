# 13 备份与恢复

## 1. 范围

管：实例备份、工作区备份、S3/WebDAV 目标、周期与保留、加密与校验、预览、整库恢复、按路径捞单篇。  
不管：S3 当主盘、多机热同步。

---

## 2. 对象与状态机

### 2.1 BackupTarget

| 字段 | 说明 |
|---|---|
| scope | `instance` / `workspace` |
| type | `s3` / `webdav` |
| endpoint 配置 | S3：endpoint、bucket、region、access_key、secret；WebDAV：url、user、password |
| prefix | |
| encryption_enabled | 备份包加密。密钥由管理员粘贴，**只存密钥指纹，加密密钥本身用实例主密钥封装或每次让管理员输入**。一期：设置时输入 passphrase，派生密钥，存 KDF 盐 + 校验，不把 passphrase 明文落盘。 |
| schedule | manual / daily / weekly |
| retain_daily / retain_weekly | 默认 7 / 4 |
| enabled | |

凭证加密存（应用级），**导出的备份包内不得再放这些凭证明文。**

### 2.2 BackupJob

`pending` → `running` → `success` / `failed`  
记录：started、bytes、checksum_sha256、remote_path、error。

### 2.3 RestorePlan / RestoreRun

恢复先建立 15 分钟有效的只读 `RestorePlan`。计划绑定 target、remote_path、checksum、格式版本、目标范围、操作者、模式和预检报告；口令与包正文不落库。`RestoreRun` 状态为：

`pending → restoring → verifying → success / failed / rolled_back`

另记恢复前检查点、统计、警告、脱敏错误与是否为演练。目标记录最近一次演练时间与结果。

### 2.3 包内容

**实例包**

- 用户资料；密码恢复为不可登录占位值，管理员须触发重置，不从包内复活认证凭据
- InstanceSettings，但 SMTP 密码、审核 API Key、VAPID 私钥始终省略
- 注册码哈希与元数据，不含已展示过的明文码
- 广场 Post、Like、广场评论
- 用户的 `saved_shares` 行（[21](./21-收到的分享.md)；只是指针，无 token、无正文）
- **不含** 任何 MCP secret、用户/工作区 AI api_key 明文

**工作区包**

- 成员与角色、笔记本 ACL
- 全部 md、附件二进制、动态附件、版本、回收站（v4 起文件以 Base64 随包并逐个校验 SHA-256）
- 圈子 Post、本区评论纠错
- 项目、任务、工时、里程碑（旧包缺这几项时按空数组恢复）
- Site 配置、ShareLink（token 视为机密，仅加密包可含）
- 标签、树、TitleIndex 可重建，但为恢复速度可带一份 dump
- 不含 MCP secret、AI key

## 3. 交互

### 3.1 配置

实例后台 / 工作区设置 → 备份：加目标、测连接（写一个小文件再删）、选周期、开加密、手动「立即备份」。

### 3.2 历史

列表：直接从 S3 / WebDAV 发现 `.kbbackup`，显示时间、大小、本地已知校验与格式。操作：下载、只读预检、恢复、隔离演练。远端对象只能从目标前缀的实际列举结果中选择，不接受 URL 或含目录穿越的路径。

### 3.3 恢复

两步：选包并预检 → 输入确认文本执行。工作区模式为：

- `new_workspace`：重新分配全部资源 UUID，恢复为新的团队工作区，默认推荐。
- `replace_workspace`：仅 Owner；冻结目标，先在同一远端目标生成恢复前检查点，再用事务替换关系数据。失败自动用检查点补偿回滚。

实例模式为 `bootstrap_empty_instance` / `replace_instance_metadata`。实例包只恢复元数据；会话、认证令牌、MCP Token 全部吊销，密码、AI/API Key、推送私钥不复活。恢复进行中目标工作区保持只读。

预检顺序：下载 → 已知 checksum 比对 → KBENC1 解密 → 严格格式/版本校验 → UUID 与引用图校验 → 附件大小/SHA 校验 → 统计、冲突和风险报告。任一步失败都不写业务数据。v3 工作区包因没有附件二进制，必须显式接受跳过附件才可继续。

## 4. 业务规则

1. 备份失败发站内信给 Owner/实例管理员。
2. 保留：超期包删除远端。删除前至少留 1 个成功包。
3. checksum 不匹配禁止恢复。
4. 加密包无 passphrase 不能预览内容。
5. 恢复不重放 MCP 钥匙、不重写 AI key。用户需重配。界面恢复完成后列出「需要重新配置的项」。
6. 实例恢复是灾难操作，仅实例管理员，且不能在线随便点——须确认短语。
7. 工作区备份不含其他区数据。
8. 同一目标同时只跑一个 job。
9. 分享 token、日历 feed token 在恢复时默认轮换并保持吊销；外部 ICS URL 在未加密包中省略并停用。
10. 恢复完成后校验核心表计数、抽样正文、附件 checksum 与 Owner 关系；验证失败不得标记成功。
11. 灾备演练在事务内实际写入隔离工作区并执行计数检查，随后主动回滚销毁，不留下临时业务资源。

## 5. 算法

### 5.1 打包

```
snapshot DB consistent rows (transaction or dump)
copy files by note_id list
tar/zip → optional encrypt(age/libsodium, passphrase KDF)
sha256
upload to S3/WebDAV
verify listing + optional download head hash
apply retention
```

### 5.2 保留

```
keep last N daily
keep last M weekly (每周最新一份)
delete others on that target/prefix
```

### 5.3 整区恢复

```
frozen=true
replace workspace rows + files
rebuild TitleIndex, search, chunks
emit 批量 NoteUpserted 或直接重建
frozen=false
```

双链、Markdown 文件、FTS / chunks 都是派生物：正文恢复后重建，不从包内信任旧索引。

### 5.4 单篇捞回

解开单文件 + 附件。若 id 冲突：新 UUID，源码 `[[ ]]` 不改（仍是标题）。告知用户。

## 6. 与其他功能的关联

| 方向 | 关系 |
|---|---|
| ← 全模块 | 包内容清单以各文档「进备份吗」为准 |
| ← 11、10 | 明文钥匙永不进包 |
| ← 07 | 分享 token 只进加密工作区包 |
| ← 21 | 收到的分享行进实例包；工作区包不收 |
| ← 12 | 回收站一并备；purge 后只能靠包 |
| → 01 | SMTP 失败不影响备份本身 |

机密分级：

| 数据 | 策略 |
|---|---|
| 笔记正文 | 进包 |
| 分享 token | 仅加密包 |
| 用户密码哈希 | **永不进新实例包，也不从旧包复活** |
| MCP secret / AI api_key | **永不进包** |
| 注册码明文 | 永不进包（只有哈希） |

当前实现进一步收紧：用户密码哈希不从实例包复活；恢复后的用户走密码重置。所有恢复口令只存在于当前 HTTP/CLI 调用内存，不进入 plan、run、background job、审计或错误日志。

## 7. 离线校验与整机灾备

```bash
# 只读校验；加密口令通过环境变量传入，避免进入 shell 历史
KB_BACKUP_PASSPHRASE='...' pnpm backup:verify ./workspace.kbbackup --checksum=<sha256>
pnpm restore:preflight ./workspace.kbbackup

# 实例元数据离线恢复（仍不等于整机恢复）
KB_BACKUP_PASSPHRASE='...' DATABASE_URL='...' pnpm restore:instance ./instance.kbbackup --maintenance
# 首次只打印确认指纹，再携带 --confirm=<checksum前12位> 执行

# PostgreSQL custom dump + kbdata tar 的整机恢复
DATABASE_URL='...' DATA_DIR='/data' pnpm restore:disaster ./postgres.dump ./kbdata.tar --maintenance
# 首次预检路径和归档，再按输出追加 --confirm=<指纹>
```

整机脚本拒绝归档路径穿越，先生成当前数据库回滚 dump，在单事务中恢复数据库，再原子切换同文件系统上的数据目录；失败会恢复数据库检查点与旧数据目录。成功后保留两份检查点供人工确认，不自动删除。
