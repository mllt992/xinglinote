## 1. 范围

### 1.1 一句话

**导航页是实例级的常用去处目录，不是第二套书签产品，也不是广场。**

管理员把本实例里真正会反复打开的站点、文档站、内部路径按分组摆好；所有人打开 `/nav` 就能按分类点进去。图标由服务端按 URL 自动抓取并落在本机，前端不直连外站图标。

### 1.2 做什么

| 能力 | 谁 | 说明 |
|---|---|---|
| 浏览导航 | 登录用户；访客视开关 | 分组 + 站点卡片，即时搜索，分类锚点 |
| 配置分组与站点 | 实例管理员 | 增删改、排序、标题与简介 |
| 自动取图标 | 服务端 | 解析页面 `<link rel="icon">`，失败再试 `/favicon.ico` |
| 开关 | 实例管理员 | 总闸、是否对访客公开、页标题与副标题 |

### 1.3 一期不做

个人书签、按工作区隔离的导航、点击统计、按人推荐、浏览器同步、拖入 Chrome 书签导入、用户上传任意 SVG 图标、外链图片直出（CSP 不允许）。

## 2. 对象与状态机

### 2.1 对象

```
Instance
 └── Nav（无独立表，开关与文案在 instance_settings）
      ├── NavGroup     分组，排序在组内
      └── NavLink      一条可点的去处，属于恰好一个分组
```

| 对象 | 字段 | 约束 |
|---|---|---|
| 实例开关 | `nav_enabled`、`nav_public`、`nav_title`、`nav_subtitle` | 默认开、默认对访客公开；标题 ≤ 20 字，副标题 ≤ 80 字 |
| NavGroup | `id`、`title`、`description`、`sort_key` | 标题 1–24 字；全站最多 30 组 |
| NavLink | `id`、`group_id`、`title`、`url`、`description`、`icon_sha256`、`icon_mime`、`sort_key` | 标题 1–40 字；简介 ≤ 120 字；每组最多 80 条，全站 400 条 |

`url` 只允许：

- 站内路径：以单个 `/` 开头（如 `/`、`/w/{id}`、`/s/ws/nb`），同页打开；
- 外链：`http` / `https`，新标签打开。

### 2.2 状态

导航页没有复杂状态机。站点要么在目录里，要么被删。没有草稿、没有上下线单条——要藏就删，或者关整页。

关 `nav_enabled`：顶栏入口消失，`GET /api/v1/nav` 回 `enabled: false` 且不带站点。管理员配置接口不受影响。

关 `nav_public`：未登录读目录回 `UNAUTHENTICATED`。图标接口对未引用且非管理员的哈希一律 `NOT_FOUND`。

### 2.3 图标

图标是内容寻址 blob（复用 `blob_store`），不进附件表。CSP 是 `img-src 'self' data: blob:`，所以**必须**由本实例代存代出，禁止把外站 favicon URL 直接塞进 `<img>`。

不接受 SVG（可执行）。只认 png / jpeg / gif / webp / ico。

## 3. 交互

### 3.1 入口

- 顶栏与笔记 / 圈子 / 广场并列，文案「导航」，路由 `/nav`。
- `nav_enabled = false` 时入口不出现。
- 管理员账号菜单里可进「实例后台 → 导航」。

登录成功默认仍进个人工作区，不改成 `/nav`。

### 3.2 浏览页

```
顶栏：身份 + 主导航 + 铃铛 / 登录
主列：问候语 + 页标题 + 搜索
左轨：分组锚点（窄屏改成横向芯片）
主区：按分组的站点卡片网格
```

- `/` 聚焦搜索；输入即时过滤标题、简介、主机名、分组名。
- 外链 `target=_blank` `rel=noopener noreferrer`；站内路径当前页跳转。
- 没有图标时用标题首字做字母块，不留破图。
- 空目录：说明「还没有站点」。管理员多一个「去配置」。
- 未登录且未公开：说明要先登录，给登录按钮。

视觉落在现代墨白里：黑白灰分层、细线、8–12px 圆角、克制纹理，不靠大投影或玻璃拟态撑场面。

### 3.3 配置

`/admin?tab=nav`：

1. 顶部：启用、对访客公开、标题、副标题。
2. 左栏分组，右栏当前组的站点。
3. 新增 / 编辑站点：填 URL 后自动取图标，可点「重新获取」。
4. 组与站点用上 / 下移动排序，不引入拖拽库。
5. 删除走 `useConfirm()`，组删了里面的站点一起走。

## 4. 业务规则

1. 只有实例管理员能写。工作区 owner 不行。
2. 读：启用且（已登录或 `nav_public`）。写永远过管理员检查。
3. 存库的外链不做 SSRF 校验——点开是用户浏览器的事。**取图标**的出站请求必须走 `assertSafeOutboundUrl`，重定向每一跳都要再验。
4. 取图标失败不挡保存，卡片退回字母块。
5. 取图标限流：同一管理员 10 分钟 20 次。
6. 删站点或换图标时 `releaseBlob`；两组站点碰巧同一哈希则靠 refcount。
7. 不记点击、不进审计日志（不是密钥或成员变更）。
8. 前端藏按钮，写仍以服务端为准。

## 5. 算法

### 5.1 取图标

输入是一条 `http(s)` URL。

1. 解析并 `assertSafeOutboundUrl`。
2. `GET` 该页，超时 8s，正文上限 400KB，最多跟 3 次重定向；每一跳重新校验。
3. 从 HTML 收集 `<link rel>` 含 `icon` / `shortcut icon` / `apple-touch-icon` 的 `href`，按 `sizes` 靠近 128px 排序；可附带 `og:image` 作弱候选。
4. 最后补上 `{origin}/favicon.ico`。
5. 逐个抓取，单文件上限 256KB；魔数识别类型，SVG / 未知一律丢。
6. 第一张合格的 `putBlob`，把 `sha256` 与 mime 写到站点上。

站点是站内路径时不抓图标。

### 5.2 搜索

纯前端：对当前目录做子序列 / 包含匹配。目录体量有上限，不走服务端搜索。

## 6. 与其他功能的关联

| 对方 | 关系 |
|---|---|
| 顶栏导航 | 第四个「地方」，与广场开关一样由 `/meta` 告知显隐 |
| 主题 / CSP | 图标只从本域出；颜色只用语义 token |
| blob_store | 图标与附件共用去重与引用计数 |
| 广场 | 彼此独立。关广场不影响导航，关导航不影响广场 |
| 文档站 / 工作区 | 可以配成站内路径，方便把已发布的站放进目录 |
| 备份 | 表在 Postgres 里，跟实例备份走；图标文件在 `data/blobs/` |

对外文案：无权或未公开时说「请先登录」，不暗示目录里有什么。图标哈希未引用时统一「图标不存在」。
