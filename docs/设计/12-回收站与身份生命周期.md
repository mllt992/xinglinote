# 12 回收站、移出成员、封禁、注销

## 1. 范围

管：笔记/目录/笔记本软删除与恢复与销毁；成员移出时私有本迁移；封禁/解封；注销宽限；工作区冻结与销毁。  
不管：评论软删细节（08）、分享 token 作废 UI（07，但本文定义联动）。

---

## 2. 对象与状态机

### 2.1 回收站条目

Notebook / Folder / Note 都有 `trashed_at`、`trashed_by`、`purge_at = trashed_at+30d`。  
目录/笔记本入站时：**级联标记**子孙 `trashed_at`（同源），恢复时按同一批还原。

```
active → trashed → purged（物理删 md、附件计数、索引、向量）
       ↘ restore → active
```

Post/Comment 不进本回收站。

### 2.2 User.status

`active` → `banned` ⇄ `active`  
`active` → `pending_deletion` → 到期 `deleted`（行可匿名残留）  
`pending_deletion` 可撤销回 active。

### 2.3 Workspace.frozen

唯一 Owner 被封且未转让：区 `frozen=true`，全员只读。解封 Owner 后解冻。

---

## 3. 交互

### 3.1 删除

树节点删除进回收站，toast「撤销（10s）」调用 restore。  
回收站页：名称、原路径、删除人、剩余天数。恢复 / 立即销毁。  
Owner/Admin 看全区；其他人只看 `trashed_by=自己` 的。恢复他人删的：仅 Admin/Owner。

### 3.2 移出成员

确认框：

- 默认勾选「将其个人私有笔记本迁回个人工作区」
- 可选「同时作废其在本区的 MCP 钥匙」（默认勾）
- 说明共享本留下

### 3.3 封禁（`/admin` 用户）

确认：踢会话、藏广场帖、作废全部 MCP、若为唯一 Owner 则必须选「指定新 Owner」或「冻结工作区」。不能封最后一个实例管理员。

解封：可登录；广场帖恢复展示；MCP 不自动恢复；冻结区若 Owner 已解封则解冻。

### 3.4 注销

自己：设置里申请，输入密码，7 天宽限可撤销。宽限内个人区只读。  
管理员代执行：同样宽限，除非勾「立即」（二次输入）。  
拦截：仍是某普通工作区唯一 Owner → 报错列出工作区，须先转让或删除。

---

## 4. 业务规则

1. trash 后：搜索/文档站/AI/MCP get 按不存在；双链 state=trashed；分享访问 404。
2. restore：Link 回到 resolved；未撤销且未到期的 ShareLink 复活；`published` 保持原值，文档站立刻又看得到。
3. 原路径被活着的同名占用：恢复到本根目录「恢复的笔记」下，必要时标题加后缀。
4. purge 不可恢复（除非整库备份）。双链变 unresolved。分享永远 404。
5. 级联 trash 笔记本：其文档站视为下线；Site.published 值保留，整本 restore 后站自动回。
6. 移出：`private` 本迁到用户个人区（保持 note id、双链 id）。目标区若有同 slug 笔记本则放进新本「从{区}迁回」。`restricted`/`open` 本留下，并把该用户从白名单删掉。
7. 迁走的本上，仅该私有本的 ShareLink 跟着走仍有效；共享内容的链接留下。
8. 封禁不删共享笔记、不改作者字段。
9. 注销到期：个人区销毁（purge 其全部笔记）；广场帖 soft delete；评论作者空、显示名「已注销用户」；钥匙全废；handle 释放在 30 天后。
10. MCP trash 与 UI 同一套，审计记 token。

## 5. 算法

### 5.1 级联 trash

```
mark(node):
  node.trashed_at = now
  if folder/notebook: for child in children if not trashed: mark(child)
emit NoteTrashed for each note
```

restore 根时只恢复 `trashed_at` 相同批次（同一 timestamp 或 trash_batch_id）。用户在回收站删过子项则子项不随父恢复——用 `trash_batch_id` 更干净。

**拍板：每次删除生成 batch_id，恢复某条默认恢复同 batch 仍处于 trash 的子孙。单独恢复子笔记也允许。**

### 5.2 路径冲突

```
if dest title conflict:
    title = title + "（恢复）"
    if still: + 数字
parent = 原 parent 若仍 active 否则 「恢复的笔记」文件夹（自动建）
```

### 5.3 迁出私有本

```
for nb in notebooks where visibility==private and created_by==user:
    reassign workspace_id = user.personal
    物理目录搬家
    重解析本内链接（跨区了）
    revoke 该用户本区 tokens if 勾选
```
