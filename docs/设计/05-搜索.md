# 05 搜索

## 1. 范围

管：工作区关键词搜索、跨工作区搜索、文档站站内搜、广场搜、过滤器、结果展示。  
不管：AI 语义问答（10，可调用本文做 hybrid 的关键词半边）、双链补全（04 用 TitleIndex，不走搜索框）。

原则：**普通搜索框要快、可解释；语义只挂在 AI / MCP。**

---

## 2. 对象与状态机

### 2.1 索引文档（关键词）

每篇活笔记一条：

- note_id, workspace_id, notebook_id, folder_path, title, aliases, tags, body_plain
- body_plain = Markdown 去语法后的文本 + 成功抽出的 PDF 文本（06）
- 不含评论、纠错、动态、分享密码

trash 的笔记从活索引删除，进回收站专用索引（仅回收站页搜索）。

### 2.2 查询范围枚举

| scope | 谁能用 | 过滤 |
|---|---|---|
| `workspace` | 成员 | 当前工作区 ∧ can_read |
| `all_my` | 登录用户 | 其所有 membership ∧ can_read |
| `site` | 任何人 | 该文档站已发布 ∧ published |
| `square` | 任何人 | 广场未删帖 |
| `workspace_feed` | 成员 | 该区圈子未删帖 |
| `shares_mine` | 登录 | 我建的分享元数据（标题），不是搜正文 |
| `shares_received` | 登录 | 我收下的分享标题快照（[21](./21-收到的分享.md)），不是搜别人的正文 |

---

## 3. 交互

### 3.1 库内搜索（左栏或 `Ctrl+K`）

默认 scope=当前工作区。切换「全部工作区」。  
过滤器：笔记本、标签、仅标题、含/不含 AI 索引（给自己整理用）。  
结果行：`标题 — 工作区 / 本 / 路径`，摘录 1–2 句高亮。键盘上下、回车打开。  
空查询：最近 + 收藏，不搜正文。

### 3.2 文档站

顶栏搜索只搜本站已发布篇。未登录可用。结果链到站内 URL。

### 3.3 广场

搜索帖子正文与作者 handle/显示名。不做用户推荐。

---

## 4. 业务规则

1. 永远先 ACL 后打分。不能先搜再漏过滤——用「索引时写入允许读的 workspace，查询时再 can_read」双保险。`private` 本只进创建者的可见集。
2. 关键词检索不返回 `EXISTS_INVISIBLE` 的篇（根本不出现）。双链可以指向它们，搜索不行。
3. 单次 20 条，可翻页到 100 条封顶。
4. 查询串最长 200 字。空格分词；中文用 ngram(2) 或同等分词，必须能搜到「账本」「家庭账本」互相关。
5. Viewer 与 Editor 同一套读过滤。
6. MCP `search_notes` 走 scope=钥匙绑定工作区 + 钥匙笔记本范围 + `can_ai_read`，见 11。不得返回全文，只 title + ≤240 字 snippet + id。

## 5. 算法

### 5.1 打分

```
score = 8 * title_hit + 5 * alias_hit + 3 * tag_hit + 1 * body_hit
      + recency_boost(updated_at, 半衰期 90 天，最大 +1)
```

同标题优先当前笔记本（scope=workspace 时）。

### 5.2 可见性物化（可选优化）

维护 `NoteVisibility(note_id, user_id)` 对 private/restricted 很有用。  
`NotebookAclChanged` / 成员变更时重算该本相关行。  
一期人少也可查询时 join ACL，但测试必须覆盖「被移出后 1s 内搜不到」。

### 5.3 索引更新

订阅 `NoteUpserted`：异步 ≤ 2s 内可见。`link_rewrite` 也更新（标题变了）。  
`NoteTrashed` 立即删活索引。失败重试，不阻塞保存。
