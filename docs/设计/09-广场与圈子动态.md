# 09 广场与圈子动态

## 1. 范围

管：Post 双时间线、发帖编辑删除、点赞、收藏、举报、公开主页、摘发与转正、圈子公开到广场的泄漏检查。  
不管：关注推荐转发（不做）、评论细节（08）。

---

## 2. 对象与状态机

### 2.1 Post

| 字段 | 说明 |
|---|---|
| scope | `instance` / `workspace` |
| workspace_id | 圈子必填；广场空 |
| body_md | ≤ 5000 字，闭集 Markdown 的子集：无嵌入笔记展开，允许 `[[ ]]`、图、任务 |
| reply_to_id | 可空，一层回复当「评论式回复」也可只用 08 的 Comment。一期：**回复用 Comment，Post 不做盖楼转发。** `reply_to` 保留但不在 UI 暴露，减少两套楼。 |
| linked_note_ids[] | 解析自 `[[ ]]` 且 resolved 的 id |
| edited_at | |
| deleted_at | 软删 |
| like_count | |

### 2.2 PostAsset

一条动态最多 9 个附件，图 / 文件 / 视频混着算。落 `post_assets`，不进笔记附件表。

| 字段 | 说明 |
|---|---|
| post_id | 可空。空 = 还没发出去的暂存，只有上传者能看、能删 |
| filename / mime / bytes / sha256 | |
| stored_name | 磁盘名，路径 `data/feed/{id}/{stored_name}` |

限额（计入用户合计，不计入某篇笔记，见 [06](./06-附件导入导出.md)）：

- 图片（png / jpeg / webp / gif）≤ 5MB
- 视频（mp4 / webm）≤ 50MB
- 其他文件（pdf / txt / md / zip）≤ 25MB，跟笔记附件同一套白名单与魔数校验

广场帖的附件未登录也能看（inline 图和视频，文件走下载）。圈子帖跟帖一样，只有成员能下。删帖时附件软删。圈子公开到广场时附件复制一份**逻辑行**，圈子里那份不动；物理文件走 `blob_store` 引用计数，不再拷一份字节。

发帖前先传到 `/posts/attachments` 拿 id，发布时带上。作者从发帖框拿掉暂存文件会立刻删物理文件。超过 24 小时还没发出去的暂存，下次有人上传时清掉。

### 2.3 Like / Favorite

点赞 `(post_id, user_id, kind=like)` 唯一。收藏 `(user_id, post_id)` 唯一，用户级，不进 MCP。访客不能赞、不能收藏。

### 2.4 Report

登录用户可举报别人的可见动态。同一人同一帖只记一条。理由：垃圾广告、辱骂、违法、色情、其他；可附一句说明。落 `content_reports`，先交 AI 复核：明确违规就下架，明确不成立就维持公开，拿不准才进人工。被 AI 下架的作者可以申诉，申诉只走人工，见 [18](./18-内容审核.md)。作者不能举自己。

### 2.5 公开主页

`/u/{handle}`：未软删的广场帖 + 该用户作为创建者或 Admin 的、已发布文档站列表（只列站，不列私密本）。被封禁：主页 404。

## 3. 交互

### 3.0 三处导航

笔记 `/w/{id}`、圈子 `/w/{id}/feed`、广场 `/` 是同级的三个「地方」，顶栏用同一个分段导航（`AppNav`）在三处之间切，当前页有选中态。问知识库是动作不是地方，放在右侧操作区，不进导航。

三处共用同一条顶栏：左边身份（工作区页与圈子页是工作区切换器，广场是 Logo）、中间导航、右边通知 + 外观 + 账号菜单。**圈子不是独立子页面**，不给「返回工作区」——退出走顶栏的「笔记」。

实例关了广场时（§4.1），导航里不出现「广场」。窄屏顶栏收起导航，圈子在左栏底部（日历 / 今天 / 圈子 / 回收站）仍可达。

### 3.1 `/` 广场

未登录只读。登录可在顶上发帖（附件最多 9：图、文件、视频）。时间线倒序。关广场时：访客看「广场已关闭」；登录仍能进工作区。

发帖框不出现在笔记三栏里。

登录后从广场点 Logo 或导航「笔记」，回**最后待过的工作区**（记在本机 `kb.last-workspace`），没有记录时回个人工作区——比一律回个人库少一次找回现场。

右栏：未登录给登录/注册；最近活跃作者、动态里提到的笔记都从已加载的时间线里推，不额外打接口；末尾给一个「去圈子」的去处。

### 3.2 工作区 `/w/{id}/feed`

成员可见。Viewer 只读。Editor+ 可发。可关 `feed_enabled`。  
`[[私密笔记]]` 对成员按 04 库内渲染。

和广场同一套两栏。只读要说清是哪一种：冻结是工作区的状态，Viewer 是自己的角色。  
右栏：圈子成员（谁看得到这条动态，Owner/Admin 带「邀请」；个人工作区直说「只有你自己」）、动态里提到的笔记、关于圈子 + 一个「去广场」的去处。

### 3.3 「发到动态」

笔记选区或整篇摘要 → 选广场或某圈子 → 预览将发出的文本（默认取选区，可改）→ 正文末尾带「来自笔记《标题》」。  
公开到广场时跑 5.1 泄漏检查。

### 3.4 「转正为笔记」

帖子菜单：选工作区（须 can_edit 某本）+ 笔记本 + 目录。新建笔记，正文=帖子 md + 文首引用原帖。`ai_index` 跟本默认。

### 3.5 圈子→广场

「公开到广场」= **复制**一条新的 instance Post，不是改 scope（避免圈子里消失）。复制前 5.1。私链变纯文本。

### 3.6 卡片操作

每条动态：赞、评论、收藏；更多里有转正 / 编辑删除（作者）/ 删除（实例管理员；圈子另加该工作区 Owner/Admin）/ 举报（别人）。评论一层楼，细则见 [08](./08-评论与纠错.md)。未登录看得到评论，要写评论走访客通道；收藏和举报必须登录。

评论按钮写清「N 条评论 / 收起评论」。本页刷新仍展开刚才打开的那楼；通知链接用 `?post=` 打开对应卡片。折叠态若有评论，卡片下给一行入口，不要只剩一个图标。

### 3.7 新动态提示

时间线**不自动往上插新帖**——人还在往下读时内容自己跳，位置就丢了。

页内每 30 秒问一次「自上次看过之后」（页签不可见时停）：

- 新动态：`created_at > since` 的可见帖
- 有新回复：帖子在 `since` 之前就在，之后有别人的可见评论

自己刚发的评论不计入「有新回复」。`since` 用服务端时间，避免本机时钟快慢。超过 7 天的 since 按 7 天截断，查询保持便宜。

有更新时时间线顶上出一条横幅：「3 条新动态 · 2 条有新回复」。点一下只重拉当前时间线、合并进列表——发帖框、已展开的评论、滚动位置都还在。新出现的帖和评论变多的帖短暂标一下。

顶栏「广场 / 圈子」和左栏「圈子」用同一个本机水位显示数字。第一次进某个时间线把水位记成「现在」，不会把历史全算成未读。已经在当前页再点一次「广场 / 圈子」= 等同点横幅。

## 4. 业务规则

1. 实例可关广场；工作区可关圈子。已有帖保留，只是入口 404/隐藏。
2. 作者可编辑（标已编辑）、软删。实例管理员可删除任何人的广场帖和圈子帖。工作区 Owner/Admin 可删除本圈子帖。
3. 动态默认不进笔记搜索、不进 AI 索引、不进 MCP，除非钥匙开了 `feed.*`（11）。
4. `#tag` 按搜索词处理：点标签 = 搜含该词的帖。无话题页。
5. handle 规则见 01。改 handle 主页旧址 30 天跳转。
6. 发广场：任何 `active` 用户。实例以后可加「需开通」，一期不加。开了内容审核时，发布先落库成功再后台过 AI，不通过转待人工，见 [18](./18-内容审核.md)。
7. 动态附件计入用户合计配额（06），不计入某篇笔记。

## 5. 算法

### 5.1 公开泄漏检查

```
for each resolved [[link]] in body:
    if not publicly_visible(target):  # 04 的 5.4 同一函数
        mark leak
if leak and dest == square:
    UI 列出将被打成纯文本的标题
    用户确认后：这些 [[ ]] 写成普通标题文本再发布
圈子内发帖: 不检查，成员自己有 ACL
```

`publicly_visible` = 文档站已发布且该篇 published 且不在审核中，**不包括**「仅有分享链接」（避免把 /p/token 间接暴露到广场）。

顺序是先泄漏检查、后内容审核：先把不公开的 `[[ ]]` 打成纯文本，再拿最终文本去审，免得审的和发的不是一份东西。

### 5.2 时间线

`ORDER BY created_at DESC LIMIT 20`。待审与被驳回的帖子只有作者本人看得到（带状态标），其他人当它不存在。无算法推荐。被封禁用户的帖 `deleted_at` 或单独 `hidden_by_ban`，解封不自动恢复展示（规格：封禁隐藏；解封后是否恢复——**解封恢复展示**，更符合「停用账号」而不是「删除内容」）。在 12 对齐：封禁隐藏，解封恢复广场帖。
