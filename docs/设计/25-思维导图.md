## 1. 范围

### 1.1 一句话

**导图是挂在笔记本下的一张可编辑脑图，节点可以指向笔记；笔记这边能看到哪些导图引用了它。**

### 1.2 一期做

- 笔记本下新建 / 改名 / 删除导图；顶栏「导图」进入工作区导图列表（按笔记本分组）
- 编辑器：加子节点（Tab）/ 同级（Enter）/ 删除、双击改字、拖动节点、滚轮缩放、拖空白平移、居中
- 自动保存到服务端（约 0.8 秒防抖；离开页面时补存），带乐观版本号，冲突提示刷新
- 节点关联笔记：选中节点 → 选笔记；点节点上的链接图标在站内跳到笔记
- 笔记右栏「思维导图」页签：列出引用本笔记的导图（点进去定位到对应节点），并可「按标题结构生成」或「用 AI 提炼」一张新导图
- 导出 PNG / JSON
- 跟随站点浅色 / 深色

### 1.3 一期不做

实时多人协同、分享 / 发布到文档站、版本历史、回收站（删除需二次确认，删后不可恢复）、连线与摘要、节点图片、MCP 工具、搜索索引、导图数据计入存储配额。

## 2. 数据

编辑器选用 [mind-elixir](https://github.com/SSShooter/mind-elixir-core)（MIT，零依赖），数据直接存它的 `nodeData` 树，但入库前经 `@kb/shared` 的 `sanitizeMindMap` 白名单清洗：

- 只保留 `id / topic / children / expanded / direction / style(白名单键) / tags / icons / hyperLink / metadata.noteId`
- 丢弃 `dangerouslySetInnerHTML`、图片、连线（arrows）、摘要（summaries）
- `hyperLink` 只接受 `#note:<uuid>` 或 http(s)；样式值拒绝 `url(`
- 上限：3000 节点、深度 40、单条主题 500 字、整体 1 MB；节点 id 必须唯一

表：

| 表 | 字段 | 说明 |
|---|---|---|
| `mind_maps` | id, notebook_id → notebooks ON DELETE CASCADE, title, data jsonb, version, created_by, updated_by, created_at, updated_at | 索引 (notebook_id, updated_at) |
| `mind_map_note_links` | mind_map_id → mind_maps CASCADE, note_id → notes CASCADE, node_id | 唯一 (mind_map_id, note_id)；索引 note_id。每次保存在同一事务里按 data 重建 |

## 3. 权限

完全跟随所属笔记本（`notebookAccess`）：能读笔记本就能看导图，能编辑笔记本才能新建 / 保存 / 改名 / 删除。笔记本在回收站里时导图随之不可访问；笔记本或笔记被彻底删除时级联清理。笔记侧的「引用本笔记的导图」只列出当前用户读得到的导图。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/workspaces/:id/mindmaps` | 可见笔记本（含 canEdit）与导图列表 |
| POST | `/api/v1/notebooks/:id/mindmaps` | `{title}` 新建空导图 |
| GET | `/api/v1/mindmaps/:id` | 导图 + 所属笔记本 + canEdit |
| PATCH | `/api/v1/mindmaps/:id` | `{expectedVersion, title?, data?}`；版本不符返回 `CONFLICT_VERSION` |
| DELETE | `/api/v1/mindmaps/:id` | 删除 |
| GET | `/api/v1/notes/:id/mindmaps` | 引用该笔记的导图（含节点 id） |
| POST | `/api/v1/notes/:id/mindmaps` | `{mode:"outline"\|"ai"}` 从笔记生成，建在笔记所在笔记本，根节点回链笔记 |

`mode=ai` 复用现有 AI 服务商与开关（实例 + 工作区都要开启，且该笔记打开了「AI 可读」），未配置时返回 `AI_NOT_CONFIGURED`；用量记为 `mindmap:generate`。

## 5. 备份

实例 / 工作区备份包含两张表；恢复时换新 id，并把导图数据里的 `#note:` 链接映射到恢复后的笔记 id。老备份包没有这两项时按空处理。
