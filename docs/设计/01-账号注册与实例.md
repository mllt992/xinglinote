# 01 账号、注册与实例

## 1. 范围

管：实例设置、第一人管理员、注册方式、注册码、登录登出、邮箱验证、找回密码、资料 / handle、会话。  
不管：工作区内部 ACL（见 02）、封禁注销后的内容迁徙（见 12）。

---

## 2. 对象与状态机

### 2.1 User

| 字段 | 规则 |
|---|---|
| id | UUID |
| email | 实例内唯一，小写存储 |
| email_verified_at | 空则不能登录（持「免验证」注册码除外） |
| password_hash | 不可逆 |
| handle | 全局唯一，`^[a-z][a-z0-9_]{2,31}$`，公开主页用 |
| display_name | 1–32 字，可重复 |
| avatar | 可选，计入用户附件配额 |
| bio | 公开主页，≤ 200 字 |
| role_instance | `admin` / `user` |
| status | `active` / `banned` / `pending_deletion` |
| created_at | 用于判定第一人 |

handle 可改，每年最多 3 次。改后旧 handle 保留 30 天重定向到新地址，期间他人不能抢注。

### 2.2 InstanceSettings（单行）

| 字段 | 默认 | 说明 |
|---|---|---|
| allow_open_registration | false | 总开关 |
| allow_email_registration | true | 须同时开总开关才对陌生人可见 |
| require_email_verification | true | |
| allow_code_registration | true | 关开放注册时仍可用 |
| allow_user_create_workspace | true | |
| square_enabled | true | |
| smtp_* | 空 | 空则邮箱验证/找回密码不可用，界面要明示 |
| first_admin_user_id | 空 | 第一次注册成功后写入，之后不再改（除非现管理员转让） |

### 2.3 RegistrationCode

| 字段 | 说明 |
|---|---|
| id / code | code 为 16+ 字符高熵串，只存哈希，明文创建时显示/导出一次 |
| max_uses / used_count | 1 = 一次性 |
| expires_at | 可选 |
| note | 管理员备注 |
| bind_workspace_id / bind_role | 可选，注册成功后自动加入 |
| skip_email_verification | 默认 false |
| status | `active` / `revoked` / `exhausted` / `expired` |
| usages[] | userId, used_at |

### 2.4 注册状态

```
填写表单 → pending_verification
        ↘（无需验证）→ active + 创建个人工作区
pending_verification + 点验证链接 → active + 创建个人工作区
pending_verification 超时 48h → 可重发；7 天未验证删除占位
```

### 2.5 第一人

```
在同一事务内：
  若 users 表无 status=active|pending_verification 的行
     且 first_admin_user_id 为空
  则本用户 role_instance=admin，写 first_admin_user_id
  否则 role_instance=user
```

并发：用实例设置行的事务锁或 `WHERE first_admin_user_id IS NULL` 的条件更新，保证只有一个管理员。

## 3. 交互

### 3.1 安装后第一次打开

1. `/` 广场为空，顶栏「登录 / 注册」。
2. 若尚无任何用户，注册页顶部提示「你将是本实例的管理员」。
3. 默认实例配置是「关闭开放注册 + 允许注册码」。**零用户时注册页例外放行一次邮箱注册**，否则永远进不去。第一人产生后，例外关闭，恢复设置。

### 3.2 注册页

按当前设置动态展示：

- 开放 + 邮箱：邮箱、密码、handle、显示名；提交后提示去收信。
- 注册码：多一个「注册码」框。码无效立刻拒绝，不创建用户。
- 两者都开：邮箱必填；码选填。填了有效码则走码的绑定工作区 / 免验证。
- 都关且已有管理员：显示「目前不开放注册，请向管理员索取注册码」；无码入口则只留登录。

验证邮件：链接 `/verify-email?token=`，一次性，24h。成功后登录并进入个人工作区，不进广场。

### 3.3 登录

- 邮箱 + 密码。未验证：不进系统，提示重发验证信。
- `banned`：文案「账号已被停用」，不说是否存在细节。
- `pending_deletion`：允许登录，横幅「将于 {date} 注销，可撤销」。
- 成功：跳到个人工作区（`/w/{personal}`），除非 `redirect` 是本站安全路径（分享页、邀请链接）。

### 3.4 找回密码

SMTP 未配置：页面写「请联系管理员重置」。  
已配置：发一次性链接，1h 有效；改密后踢掉所有会话。

### 3.5 实例后台 `/admin`（仅实例管理员）

页签：概览、注册策略、注册码、用户（封禁/提升管理员/注销）、广场开关、SMTP 测试、实例备份（见 13）。

注册码：

- 批量生成：数量 1–200、可用次数、过期、备注、绑定工作区+角色、是否免邮箱验证。
- 列表：已用/剩余、使用者、作废。
- 导出：仅新生成的明文码当次可下载 csv，刷新后不再给明文。

### 3.6 资料设置

改显示名即时生效。改 handle 二次确认。改邮箱走验证。改密码要求旧密码。

## 4. 业务规则

1. 邮箱、handle 占用：未验证占位也占唯一约束，防抢注。
2. 密码：≥ 10 位，须含字母和数字。不在前端做「强度评分」也能过。
3. 同一邮箱 10 分钟内最多 5 次登录失败，锁 15 分钟。
4. 验证信 / 找回信同一邮箱 10 分钟最多 3 封。
5. 实例管理员至少保留 1 个。撤销自己的管理员身份前必须先指定另一人。
6. 普通用户不能把自己升为管理员。
7. 个人工作区在 `UserRegistered` 且用户变为 `active` 时创建，不在 `pending_verification` 时创建，避免垃圾占位堆工作区。
8. 注册码：校验顺序为作废 → 过期 → 次数用尽 → 哈希匹配。成功后 `used_count+1`，达上限标 `exhausted`。绑定工作区已删除则忽略绑定，仍允许注册。
9. `skip_email_verification=true` 的码：用户仍建议填邮箱（找回密码用），但可立即登录。
10. 关闭开放注册后，进行中的 `pending_verification` 仍可点旧链接完成（链接未过期）。

## 5. 算法

### 5.1 注册码校验

```
input plaintext
row = lookup by hash(normalize(plaintext))
if not row: VALIDATION 注册码无效
if row.status == revoked: VALIDATION 注册码已作废
if now > expires_at: mark expired; VALIDATION 已过期
if used_count >= max_uses: VALIDATION 已用完
return row
```

生成：`base32(random 16 bytes)`，去掉易混字符，分组显示 `XXXX-XXXX-...`。存储 `sha256(code)`。

### 5.2 第一人判定

```
BEGIN
  lock InstanceSettings
  if first_admin_user_id is null AND NOT EXISTS active users:
      create user as admin
      set first_admin_user_id
  else
      create user as user
COMMIT
```

零用户例外开放注册，与「默认关开放注册」同时成立：判断条件是 `users` 空，而不是改设置项。第一人提交成功后例外消失。

## 6. 与其他功能的关联

| 方向 | 关系 |
|---|---|
| → 02 | `UserRegistered(active)` 创建个人工作区；注册码可带 `bind_workspace` |
| → 09 | handle 决定 `/u/{handle}`；登录后离开广场 |
| → 12 | 封禁踢会话；注销改 status |
| → 13 | 用户与注册策略进实例备份；密码哈希进备份，MCP 钥匙明文不进 |
| ← 邮件 | SMTP 空则邮箱注册应在后台标红，否则用户卡在验证 |

发出事件：`UserRegistered`、`UserEmailChanged`、`UserHandleChanged`。
