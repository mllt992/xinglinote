# 笔记标题布局（Issue #36）

笔记标题放在**笔记页顶栏**（面包屑旁的紧凑区），不再占用编辑区上方的展示级大输入。

| 能力 | 口径 |
|---|---|
| 位置 | 笔记 chrome（`h-14` 顶栏），见 `NoteTitleChrome` |
| 过长 | CSS `truncate` / ellipsis |
| 全文 | `title` 属性（悬停） |
| 复制 | 顶栏按钮一键复制，成功走 `useToast`（禁止 `alert`） |
| 编辑 | 可编辑时内联 input（`placeholder="无标题"`，兼容 App 里输入法 composition 钩子） |

## 实现落点

- 组件：`apps/web/src/components/note-title-chrome.tsx`
- 构建期变换：`apps/web/compact-note-title-plugin.ts`（挂在 `vite.config.ts`），把 `App.tsx` 里的大标题输入挪到顶栏并接上复制；**幂等**，源码若已含 `note-title-chrome` 则跳过。
  （`App.tsx` 约 160KB，超出 MCP 单次改文件体积习惯上限，故用变换落地；行为与直接改 `App.tsx` 一致。）

设计 17 §3.2 / §3.10 中「标题输入框给折叠槽让位」的旧口径由顶栏方案取代；`.editor-measure > input` 相关样式可视为遗留。
