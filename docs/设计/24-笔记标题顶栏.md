# 笔记标题布局（Issue #36）

笔记标题放在**笔记页顶栏**（面包屑旁的紧凑区），不再占用编辑区上方的展示级大输入。

| 能力 | 口径 |
|---|---|
| 位置 | 笔记 chrome（`h-14` 顶栏），见 `NoteTitleChrome` |
| 过长 | CSS `truncate` / ellipsis |
| 全文 | `title` 属性（悬停） |
| 复制 | 顶栏按钮一键复制，成功走 `useToast` |
| 编辑 | 可编辑时内联 input（`placeholder="无标题"`，兼容输入法 composition） |

设计 17 §3.2 / §3.10 中「标题输入框给折叠槽让位」的旧口径已由顶栏方案取代；`.editor-measure > input` 相关样式可视为遗留。
