# 网页剪藏与「存到星璃」

## 一期范围

- `/capture` 可粘贴普通 HTTP(S) / 微信公众号文章 URL；服务端 Readability 清洗正文，微信公众号优先取 `#activity-name`、`#js_content` 和 lazy 图片。
- Chrome / Edge MV3 扩展：官方 Mozilla Readability，主动读取当前标签页或选中片段；`activeTab + scripting + storage`，无常驻网站授权、Cookie / API key。源码、构建方法见 `extensions/clipper/README.md`；前端构建生成下载 ZIP，不发布商店。
- 剪藏书签为无扩展兜底；仅截取选中片段或 article/main/js_content 候选正文，来源 CSP 可能阻止跨站表单提交。
- 图片先列 URL，不自动加载；用户选中后保存为站内附件，未选、超限、防盗链或下载失败均降级为普通来源链接。
- 可指定工作区、笔记本和目录；默认个人私密「收件箱」，标记 `待整理`，新建收件箱默认关闭 AI 索引，任何剪藏都不会自动公开。其它目标遵循笔记本 AI 默认值。
- 未登录内容暂存在同一标签页，登录后再明确确认；服务器保存后是普通笔记，可跨设备继续整理。没有匿名云端队列。
- PWA manifest 的 GET share_target 接收 URL/title/text；是否在操作系统分享面板显示由浏览器决定，不承诺所有微信/iOS版本支持。

## 隐私与会话边界

匿名 `/api/v1/clips/bridge` 只校验有界表单数据并返回转义 JSON + 同源外部脚本，没有数据库读写和网络抓取。内容经同一标签页 sessionStorage 到确认页，不依赖 opener，不降低 COOP/CSP。外部网页不能借此自动保存笔记；真正保存必须登录并点击。

确认页临时草稿明文、按账号隔离，只留当前标签页最多 5 条；关闭标签页会丢失，应先保存或导出。存储不可用会保留当前内存并明确提醒。请求进行中按用户/草稿 ID 互斥，记录冻结的目标和输入快照。响应丢失后重试不改变内容；新草稿与旧请求独立，晚响应不清掉新内容。账号变化重新挂载，不展示另一个账号草稿。

## 服务端安全与一致性

- 所有读取目标、创建收件箱和保存均使用现有统一 ACL；事务内再次核验权限、待注销/冻结状态、目录归属和配额。
- 幂等 ID 绑定用户、笔记本、capture 类型和客户端随机 ID；请求摘要写入 notes.capture_hash。相同 ID 不同输入返回 409，不能跨用户读到既有记录。
- `notes.capture_hash` 是可空增量列，旧笔记不变。正文/附件/版本/index job 同一事务；配额与 blob 使用同一连接，无连接池内嵌等待。SHA 锁和失败清理复用迁移导入协议，不删除其它并发引用。
- 公网抓取不转发 Cookie/Authorization，标准 HTTP(S) 端口、无 URL 用户信息；逐跳检查所有 DNS 结果并固定已验证 IP，保留原主机 TLS 验证。拒绝私有/保留地址、IPv4 映射和隧道 IPv6、超过 4 跳及非 200。
- 禁用内容压缩并按流限制字节；正文 1 MB、7,000 节点、100 层；HTML 不执行脚本、外部资源或表单。正文转换继续走白名单和 Markdown 安全规则。
- 图片最多 10 张、每张 3 MB、累计下载预算 10 MB、累计 16M 像素，图片魔数和尺寸验证；每张 2.5 秒，保存网络总期限 9 秒。下载失败也消耗其预留预算，避免反复大响应绕过。
- 抓取/转换全局最多 8 个、单账号最多 2 个，同时限制每账号 10 分钟 120 次。所有捕获 API 响应 no-store。
- 不绕过来源登录、验证码、付费墙；正文失败保留具体错误，用户可主动选「只存链接」。

## 验证与边界

单元测试覆盖普通文章片段、公众号标题/正文/lazy图、链接与结构限额、所有 DNS 答复与跳转地址检查、桥接数据转义、跨组件重复提交和账号草稿隔离。真实 PostgreSQL 用合成内容覆盖 ACL、配额、并发幂等、图附件读取、下载失败链接、注入写入故障后的事务/磁盘回滚。

Chromium 验收使用打包的同一 Readability/正文脚本在合成页面实际执行，经跨站表单、匿名登录中断、375px预览取消、目标目录、重复保存、延迟请求与新草稿、登出隔离。保存计时只衡量本地合成正文确认提交到笔记入库，不包含用户选择目标的思考时间。它不等于浏览器工具栏 activeTab 授权界面、真实微信公众号成功率、实际防盗链图片或 iOS 分享面板验收；这些外部环境限制应单独记录，不能声称 70% 实测达标。

二期的语雀/知乎/飞书专项适配，以及剪藏时自定义 tags/ai_index/公开发布选项不在本次范围。普通可读网页仍可使用通用正文提取。
