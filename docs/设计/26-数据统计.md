# 26 工作区与笔记本数据统计

## 1. 范围与入口

首期 Web 页面复用设置壳与现有主题，不引入图表依赖。统一入口 `/w/:wsId/analytics`，`notebookId` 查询参数可直接打开一本的统计；页内笔记本选择器、对比条形图和浏览器前进/后退保持联动。7/30 天切换保存在 `days` 参数中。工作区和笔记本入口对所有有读取权限的成员开放。

## 2. 权限与实时口径

- 每次请求在数据库的同一个查询快照里重新查工作区成员和笔记本权限，不缓存用户统计。
- 所有总量、笔记本名称、分布、趋势、任务和双链都先限定在当前用户能读的、未删除的笔记本与笔记。Owner/Admin 不获得他人 private/restricted 本的隐式权限。
- 目标笔记本不存在、跨工作区、已删除或不可读时统一返回 NOT_FOUND；工作区不可读也不返回任何统计。
- 双链两端都必须属于本工作区且对当前用户可读、未删除；去重同一有向笔记对，忽略自链、未解析链接。单本下钻保留它与其它可读笔记本之间的连接，不暴露不可见目标的数量。
- 使用实时 SQL 聚合，正文只在数据库内计算字符量，不下发到 API 进程或浏览器。一次聚合查询返回汇总与分组，避免逐篇 ACL/N+1。序列固定 7/30 个 UTC 自然日（含今天），文件夹、标签排行最多 8 条；笔记本比较默认显示前 8 本，支持按笔记数、正文字符量、近期编辑笔记数切换并展开全部，选择器提供全部可读笔记本。
- 响应 `Cache-Control: private, no-store`；切换工作区或遇到权限错误立即移除旧数据。前端中止过时请求，忽略其结果。

## 3. 指标定义

| 指标 | 口径 |
|---|---|
| 笔记/笔记本/文件夹 | 当前可读范围内未删除条目，不含回收站 |
| 字符量 | Markdown 正文 `char_length`，含语法标记和空白，不含标题；不是分词后的字数 |
| 附件/图片/占用 | 活跃笔记下未删除附件引用；图片为 image/*，占用是逻辑字节数，非去重后物理磁盘占用 |
| 新建趋势 | 当前活跃笔记的 created_at 所在 UTC 日期 |
| 编辑笔记趋势 | 当天有 version > 1 的留存历史快照的不同笔记数；同一天一篇只计一次 |
| 版本快照趋势 | 当天留存的 note_versions 行数；含初版，5 分钟合并与历史清理会影响数字，不是逐次自动保存日志 |
| 文件夹分布 | 当前笔记的直接所属目录；无有效目录者为「根目录」。最多展示 8 组，并明确其余笔记数 |
| 标签分布 | 一篇笔记内同名标签去重，可多标签，合计可超过笔记总数。最多展示 8 个标签 |
| 内容连接 | 两端可读的有向双链数、存在至少一条可读入链/出链的笔记数与孤立笔记比例 |
| 任务完成 | source=note、link_state=linked、kind=task、未删除且来源笔记可读的同步 Markdown 任务；不含手动日历/项目任务或已脱离正文的任务 |
| 已发布笔记 | published=true 且 moderation_status=none 且所属笔记本文档站已上线 |

统计反映当前可读的活跃内容；删除、恢复、迁移、权限变化和版本保留策略会改变历史图表。空工作区/空笔记本返回零，不制造趋势。

## 4. 交互与可访问性

- 首屏骨架、页内可重试错误、权限不足提示、无可读笔记本与无笔记的空态。
- 筛选刷新时同工作区数据保留但明确标注旧范围与正在刷新；只在新响应到达后更换图表，避免标题与数据错配。
- 图表使用语义色，浅色、深色、自定义强调色一致。创建是实线，编辑是虚线，快照是点线，不能仅靠颜色区分。
- 图表提供可访问名称、日期/数量的焦点提示和「查看每日数据」表格。笔记本条形图是原生按钮，支持键盘下钻。
- 动效仅使用短时 opacity/transform/宽度过渡，全部遵守 prefers-reduced-motion；不使用大面积渐变或弹跳。

## 5. 验证

纯单测检查 UTC 跨月/闰年窗口、7/30 天参数与 SQL 参数化。显式临时 PostgreSQL 集成测试验证真实汇总、零填充、重复标签/链接、private/restricted/已删除/跨区边界、移除成员后的权限失效及 HTTP 缓存策略。浏览器验收覆盖工作区/笔记本切换、快速切换和后退、明暗/窄屏、骨架/错误/空态及 reduced-motion。
