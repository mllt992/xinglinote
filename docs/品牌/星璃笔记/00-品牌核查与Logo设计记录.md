# 星璃笔记：品牌核查与 Logo 设计记录

> 记录日期：2026-08-17  
> 结论性质：公开网络初筛与设计记录，不构成商标法律意见，也不能替代国家知识产权局商标检索、注册商实时查询或律师意见。

## 1. 名称方案

- 中文产品名：**星璃笔记**
- 英文辅助名：**Xingli Notes**
- 简称：**星璃 / Xingli**
- 核心解释：星代表灵感与知识节点；璃代表通透、折射与多面连接；笔记说明产品品类。
- 品牌短句：**记录想法，连接知识。**
- 形象文案：**让每一个想法，折射新的光芒。**

### 2.2 初筛发现

1. 搜索结果中**未发现明确名为“星璃笔记”的同类主流笔记或知识库产品**；中国区 Apple Search API 对“星璃”和“星璃笔记”的宽泛结果中，也未发现应用名包含对应精确字串。这是“本次未检出”，不是“法律上可注册”。
2. 中文短名“星璃”已有公开软件与内容项目使用：包括“星璃 AI伴侣”“星璃云图”“星璃博客”等。因此不建议只使用“星璃”，尤其产品未来加入 AI 助手时，应关注与“星璃 AI伴侣”的混淆可能。
3. `Xingli` 同样并非独占词：公开结果可见 **星黎 Studio / 星黎 AI** 等软件项目，英文拼写和读音相近；另有 `Xingli` 文具商品。因此不建议把裸英文 `Xingli` 当作唯一识别手段。
4. 裸域名中，`xingli.com` 已注册（公开 WHOIS 显示注册日期为 2001-10-21），`xingli.cn` 显示出售页，`xingli.app` 已注册并使用 Cloudflare；三者均不能按“可直接注册”处理。
5. `xingli.ink`、`xingli.wiki` 未发现有效网页且注册局 RDAP 初查未找到对象；`xinglinote.com`、`xinglinotes.com`、`getxingli.com`、`usexingli.com` 在 2026-08-17 查询 Verisign `.com` 官方 RDAP 时均返回 HTTP 404（注册局当时未返回域名对象）。这些只能视为**查询时刻疑似尚未注册**；状态随时会变化，购买前仍须由注册商实时确认并立即下单。使用 `getxingli.com` / `usexingli.com` 还存在用户误访 `xingli.com` 的流量风险。本地 DNS 会把不存在或未知域名映射到 `198.18.0.0/15` 测试网段，因此 DNS 结果未被用作判断依据。
6. 中国商标层面必须继续在官方渠道按文字、拼音和近似字检索，重点关注：
   - 第 9 类：可下载软件、移动应用；
   - 第 42 类：SaaS、软件设计与托管；
   - 视业务增加第 35 类（在线平台经营/推广）与第 41 类（出版、教育内容）。

## 3. 风险判断

| 项目 | 初筛判断 | 说明 |
|---|---|---|
| 中文“星璃笔记”同类产品冲突 | 低—中 | 未发现明显同名主流产品，但官方商标库尚需人工精确/近似检索 |
| 中文“星璃”近似商标 | 中 | 两字短词近似空间大，应检索星丽、星黎、星力、星礼等近似音形 |
| 英文“Xingli”独占性 | 中—高 | 拼音对应多个中文词，已有近名软件及商品 |
| `xingli.com` / `.cn` / `.app` | 不可直接注册 | `.com`、`.app` 已注册，`.cn` 显示出售页 |
| `.ink` / `.wiki` 与组合 `.com` | 查询时疑似可注册 | 注册局 RDAP 当时未找到对象，但仍须在注册商实时确认后立即购买 |

**阶段结论：** 可以把“星璃笔记”作为工作品牌推进 Logo 与产品内测；在公开发布、投放或印刷前，先完成第 9/42 类官方近似检索并提交商标申请。对外应始终优先使用完整中文名“星璃笔记”，英文使用 `Xingli Notes`，避免只写 `Xingli`。

## 4. Logo 设计目标

现有 UI 已锁定为“现代墨白”：95% 黑白灰、细边框、克制圆角、长时间读写优先。因此 Logo 不采用大面积蓝紫渐变、具象星空或复杂玻璃拟态，而是在黑白系统里用灰阶切面表达“璃”。

Logo 需要适配：

- 28px 顶栏品牌图标；
- 浏览器 favicon；
- 登录页和公开文档站横版字标；
- 浅色、深色和可换主题色环境；
- 单色印刷与小尺寸显示。

## 5. 概念草稿与取舍

草稿文件：[`01-logo草稿.svg`](./01-logo草稿.svg)

### A · 星页

四角星中嵌入类似书页分栏的十字。能同时说明“星”和“笔记”，但 16–24px 下内部负形过碎，容易像医疗十字或闪光图标。

### B · 星轨

轨道、节点与中心星表达双链知识图谱。功能叙事准确，但与大量 AI、天文产品的图形语言接近，识别度不足，也偏离现代墨白的克制感。

### C · 璃光（选定）

以一枚四角星作为基础轮廓，再把星体拆成三块灰阶切面：

- 四角星：一个想法被记录时亮起；
- 中心交点：知识连接的节点；
- 灰阶切面：琉璃折射，同一条知识产生多个视角；
- 圆角黑底：与现有实心主按钮和现代墨白 UI 同源。

其轮廓在 16px 仍能辨认，灰阶丢失时也能退化为单色星标。

## 6. 定稿规范

### 6.1 构图

- 标志画布：64 × 64；
- 容器圆角：15；
- 主星视觉范围：44 × 44；
- 安全区：标志四周至少保留标志高度的 1/4；
- 32px 以下优先使用图形标，不放文字。

### 6.2 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#111111` | 标志底、主字色 |
| 星白 | `#FFFFFF` | 星体主体 |
| 璃灰 1 | `#D4D4D8` | 上左折射面 |
| 璃灰 2 | `#A1A1AA` | 下右折射面 |
| 雾白 | `#F4F4F5` | 中央高光切面 |

品牌色保持中性；产品主题色仍由用户自定义，Logo 不与主题系统争夺颜色预算。

### 6.3 字标

- 中文：`星璃笔记`，使用系统现代无衬线粗体；
- 英文辅助：`XINGLI NOTES`，小号全大写并拉开字距；
- 字标不作为注册字体作品，正式商业物料若要固定字形，可后续制作定制中文字形。

### 6.4 禁止用法

- 不添加蓝紫霓虹外发光；
- 不旋转或压扁主星；
- 不把灰阶切面随机换成多色渐变；
- 不在复杂照片上直接放标准版，应使用单色版或加纯色承载底；
- 不单独把通用四角星当作商标使用，尽量保留圆角底与切面组合。
