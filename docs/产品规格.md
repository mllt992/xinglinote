# 知识库产品规格

> 状态：已收口的产品定义，供后续架构与实现对照。  
> 本文只定「做什么 / 不做什么 / 规则是什么」，不定技术栈与接口细节。

---

## 1. 产品一句话

每人先有一个私人大脑（个人工作区）；可以再建家庭 / 团队工作区；整理过的知识发成文档站；未整理的想法进广场或圈子；AI 只通过带权限的 MCP 进入被授权的库。

对人是「笔记本 → 目录 → Markdown」的笔记软件；对 AI 是可检索、可读写的外部记忆。访客看到的是知识社区；登录后回到三栏笔记。两套皮肤，一份数据。

## 2. 已锁定决策

| 主题 | 决定 |
|---|---|
| 部署 | 自托管服务器；主存储在本机，S3 / WebDAV 只做备份 |
| 用户规模 | 第一天就支持家庭 / 小团队，不是后期补多用户 |
| 工作区 | 用户自建；注册后默认拥有个人工作区；个人工作区不可邀请他人 |
| 实例管理员 | **本实例注册的第一个用户即为实例管理员** |
| 知识结构 | 笔记本 → 目录 → 内容；扁平三栏，守住这个心智 |
| 链接 | Obsidian 级双链 + 反向链接；源码存标题，库内绑 ID；改名 / 移动不碎链 |
| 跨工作区 | 支持跨工作区搜索与双链；MCP 钥匙绑定一个工作区 |
| 正文 | Markdown 是源文件；语法有闭集；附件有限额 |
| 分享 | 单篇、单节 / 附件、目录、整本对外文档站；一篇可多条链接 |
| 分享链接 | 与文档站生命周期独立；可设密码、有效期；有管理页，可取消 |
| 文档站 | 源笔记的实时只读投影，不是另存发布包 |
| 对外站互动 | 访客可评论、可纠错 |
| 首页 | 公开动态，类似推特；大家都可以发 |
| 登录落点 | 登录后进入个人工作区，不是停在广场 |
| 动态范围 | 全站一个广场 + 每个工作区内部圈子动态 |
| 评论审核 | 登录用户直发；访客先审后发 |
| 发布审核 | 可选。开了之后发广场 / 发圈子 / 公开文章先过 AI，不通过转人工复核 |
| 回收站 | 笔记 / 目录 / 笔记本进回收站；成员移出、封禁、注销按生命周期处理 |
| AI | 可配置模型；用于管理、写作、编辑、问答 |
| `ai_index` | 人可见 ≠ AI 可读；**默认允许 AI 读取**；笔记本可改新笔记默认值，单篇可覆盖 |
| MCP | 钥匙 = 用户 + 一个工作区；笔记本范围可多选或跟随工作区权限；独立读写控制 |
| MCP 连接 | 标准协议，开源友好；支持一键复制客户端配置、钥匙轮换 / 吊销 |
| 注册 | 可配是否开放；支持邮箱验证注册、注册码注册、批量生成与管理注册码 |
| UI | 出厂「现代墨白」；明暗跟随系统；用户可配主题色；支持安装 / 制作主题包 |

## 3. 知识三态

用「三态」防止做成互不相干的「笔记软件 + 微博」。

| 态 | 入口 | 是什么 | 典型动作 |
|---|---|---|---|
| 库 | 工作区三栏编辑器 | 笔记本 / 目录 / Markdown / 双链 | 写、整理、MCP 读写 |
| 站 | `/s/...`、分享链接 | 已发布的只读文档 | 阅读、评论、纠错 |
| 流 | `/` 广场、工作区动态 | 短 Markdown 动态 | 发、赞、评、转正成笔记 |

三态必须打通：

- 动态 → **转正为笔记**（选笔记本 / 目录，保留原帖链接）
- 笔记选区 → **发到广场** 或 **发到本工作区动态**（带回链）
- 文档站纠错被接受 → **写回源笔记并生成新版本**（站点立刻更新，因为站是实时投影）

动态与笔记是不同对象：时间线的赞、评、审核不塞进目录树。二者共用同一套 Markdown 解析、附件和 `[[双链]]`。

## 4. 对象模型

```
Instance（一次部署 = 一台知识社区）
 ├── 注册策略 / 注册码 / SMTP / 广场开关 / 内容审核配置
 ├── 第一个注册用户 = 实例管理员
 ├── Users
 │    ├── 个人工作区（注册时自动创建，不可删除，不可邀请）
 │    └── 用户还可自建更多工作区
 ├── 广场 Posts（scope = instance）
 └── Workspaces
      ├── Members + Roles
      ├── AI Provider 配置
      ├── Backup 任务
      ├── 圈子动态 Posts（scope = workspace）
      ├── Recycle Bin
      └── Notebooks
            ├── default_ai_index    # 本内新笔记默认是否进大脑；系统默认 true（允许）
            ├── Folders（可嵌套）
            └── Notes（Markdown 本体，稳定 UUID）
                  ├── Heading / 锚点
                  ├── Attachments
                  ├── Links / Backlinks
                  ├── Share Links[]   # 独立生命周期，可多条
                  └── Versions
```

横切能力（不是第四级目录）：

- 标签（属于工作区）
- 双向链接 / 反向链接
- 收藏、置顶、最近（属于个人，不进 MCP）
- 评论、纠错
- 分享链接、发布站点配置
- MCP 密钥与审计
- 回收站

## 5. `ai_index` 是什么

产品上的开关：**这篇能不能进 AI 大脑**。人可以看，不代表 AI / MCP 可以读。

### 5.1 人话

打开一篇笔记时，除了「谁能看」，还有：

> **允许 AI / MCP 检索这篇**

- **开（默认）**：问答、语义搜索、MCP `search_notes` / `ask_knowledge` / `get_note` 可以读到它（仍要过你本人的 ACL）
- **关**：你自己在三栏里能看能改，AI 当它不存在

**系统默认是开：允许 AI 读取。** 不做选择时，新笔记本、新笔记都会进大脑。日记、账本、密码这类要挡 AI 的，再在本或篇上关掉。

三个开关：

| 开关 | 管什么 | 系统默认 |
|---|---|---|
| ACL / 笔记本可见性 | 家里谁能打开 | 跟笔记本走 |
| `published` | 是否出现在对外文档站 | 关 |
| `ai_index` | 是否允许被 AI / MCP 检索 | **开（允许读取）** |

### 5.2 笔记本级默认

每个笔记本有一项：**本内新建笔记默认是否进大脑**（`default_ai_index`）。

- 新建笔记本：这项也是 **开**
- 用户可以把某个本改成关（例如自己建一个「日记」「账本」），之后在这个本里新建的笔记默认不进大脑
- 改本的默认值 **只影响之后新建的**，不批量改已经存在的篇

规则：

- 新建笔记：继承当时所在笔记本的 `default_ai_index`（因此默认也是允许 AI 读）
- 单篇可以再改，覆盖本的默认（把一篇工作笔记移出大脑，或把一篇已关闭的日记临时喂给 AI）
- 笔记挪到另一个本：不自动改已有 `ai_index`，避免误开或误关；需要的话人自己改
- MCP 钥匙若勾了「只允许碰 `ai_index=true`」（默认勾），被关掉的篇对这把钥匙隐形

frontmatter 示例（仅在要挡 AI 时才需要写成 false）：

```yaml
id: 7f3c...
title: 家庭账本 2026
published: false
ai_index: false          # 覆盖默认：人能看，AI / MCP 不能检索
share_enabled: false
```

## 6. 账号、工作区、权限

### 6.1 实例与工作区

- 一台服务器是一个 Instance。
- **本实例第一个成功注册的用户自动成为实例管理员。** 之后的用户都是普通用户，可由实例管理员提升。
- 用户注册后自动获得 **个人工作区**，自己是 Owner。个人工作区不能删除，只能清空内容；**不能邀请成员**。要共事，必须另建工作区。
- 用户可再创建工作区（家庭、项目组）。实例管理员可关闭「普通用户创建工作区」。
- **实例管理员 ≠ 工作区管理员**。前者管注册、广场、封禁、SMTP、实例备份；后者管本区知识、成员、发布、工作区备份。
- 实例管理员不自动拥有各工作区内容权。进入他人私密本必须走紧急接管（仅 Owner 可发起，二次确认 + 审计）。实例管理员封禁 / 注销账号不等于能读私密笔记。

### 6.2 工作区角色

| 角色 | 能力 |
|---|---|
| Owner | 删除工作区、转让所有权、管理成员、备份、AI 密钥、查看全量审计 |
| Admin | 管理成员、创建笔记本、配置分享策略 / 发布文档站、管理本区 MCP 策略 |
| Editor | 在被授权的笔记本里读写、分享单篇 / 单节 / 目录、使用 AI、管理自己的 MCP 钥匙 |
| Viewer | 只读；不能开 MCP 写；不能创建分享 |

### 6.3 笔记本 ACL

| 类型 | 谁能进入 |
|---|---|
| 个人私有 | 仅创建者 |
| 指定成员 | 白名单 + 每人本内角色（编辑 / 只读） |
| 工作区开放 | 工作区成员按角色进入 |

补充规则：

- 个人私有笔记本，Admin 默认也进不去。
- 子目录、单篇一期继承笔记本权限。
- 公开分享、对外站是对外只读通道，不改变对内 ACL。
- 双链可以指向无权笔记，预览 / 嵌入 / MCP 一律截断为「存在但不可见」。

### 6.4 已有用户进入工作区

注册码只服务**新用户**。已经有账号的人靠：

- 工作区邀请链接（可设过期、可作废）
- 或管理员按用户名 / 邮箱添加并指定角色

### 6.5 协作策略（一期）

- 自动保存 + 版本历史。
- 展示「谁正在看 / 谁刚改过」。
- 冲突：后写覆盖，前一版进历史，可一键回滚。
- 不做实时光标。

## 7. 回收站与身份生命周期

### 7.1 回收站

工作区有独立回收站，Owner / Admin 可看全区；普通成员只看自己丢掉的。

| 对象 | 行为 |
|---|---|
| 笔记 / 目录 / 笔记本 | 软删除进回收站，默认 30 天后销毁；可手动清空或恢复到原路径（路径被占则恢复到「恢复的笔记」） |
| 双链指向已删笔记 | 显示「已删除」，不假装从来没有；恢复后链接自动活 |
| 已发布 / 已分享的篇进回收站 | 文档站投影消失；分享链接访问得到「已删除或不存在」；恢复后按原设置复活（若链接本身未过期、未被取消） |
| 动态 / 评论 | 不进回收站；作者可删，管理员可隐藏（软删，广场不再出现） |

MCP 默认无 `delete`。若持高危钥匙删除，同样进回收站，审计里记钥匙 ID。

### 7.2 移出成员

- 可移出；可选是否同时作废其本区 MCP 钥匙、本区邀请。
- 他在本区的**个人私有笔记本**迁回其个人工作区（或随回收站走，二选一在操作时确认，默认迁回）。
- 工作区开放 / 指定成员的共享笔记本留在本区。
- 他创建的分享链接：共享内容上的链接保留（属内容）；仅附着在其私有本上的链接随本走或失效。
- 圈子动态仍在，作者显示原名；被封禁后再说隐藏。

### 7.3 封禁

仅实例管理员。

- 立即不能登录，现有会话失效。
- 广场帖、公开主页隐藏。
- 其参与的共享笔记**不删**，以免拆掉家庭 / 团队知识。
- 其所有 MCP 钥匙立即作废。
- 其作为唯一 Owner 的非个人工作区：封禁前应先转让；未转让则实例管理员只能「冻结工作区」（只读，不能看私密本内容细节以外的元数据？——冻结 = 成员暂不能写，内容仍按原 ACL 存在）。一期简化：**封禁前若仍是某区唯一 Owner，必须先指定新 Owner 或冻结该区为只读。**
- 可解封；解封不自动恢复 MCP 钥匙，需自己重发。

### 7.4 注销

用户本人申请，或实例管理员执行。

- 个人工作区及其回收站销毁（过宽限期，建议 7 天可撤销）。
- 评论改为「已注销用户」，正文保留（避免文档站讨论被挖空）。
- 广场帖删除（软删）。
- 必须先处理「仍为 Owner 的非个人工作区」：转让或删除工作区，否则不让注销。
- 共享笔记中的作者名保留为当时显示名，账号解绑。
- API Key / MCP 钥匙全部作废；备份里本来就不存明文 Key。

## 8. 注册与准入

实例级可配置：

| 项 | 说明 |
|---|---|
| 是否开放注册 | 总开关 |
| 邮箱注册 | 必须验证邮箱后才能使用 |
| 注册码注册 | 可与邮箱并行；也可「只允许持码注册」 |
| 注册完成后 | 一律创建个人工作区 |
| 第一人 | 第一个成功注册的用户 = 实例管理员 |

注册码作为家庭 / 班级入场券：

- 批量生成：数量、可用次数（1 = 一次性）、过期时间、备注
- 可选绑定：自动加入某工作区 + 指定角色
- 列表、作废、查看被谁使用、导出
- 关闭开放注册时，持有效注册码仍可注册

建议实例默认：**关闭开放注册，只开注册码**。空库安装完成后，用注册码或临时开放一次注册产生第一位管理员，然后按需关掉。

## 9. 笔记、双链、跨工作区

### 9.1 排版

扁平三栏，目录树只服务「当前打开的笔记本」：

```
┌────────────┬──────────────┬──────────────────────────┐
│ 工作区切换  │ 当前本目录树  │ 标题 + 面包屑 + 发布状态    │
│ 笔记本列表  │ 双链 / 反向   │ Markdown 源码 | 预览        │
│ 全局搜索    │              │ 右侧：反向链接 / AI / 版本   │
└────────────┴──────────────┴──────────────────────────┘
```

原则：

- 新建默认落在当前笔记本 / 当前目录。
- 支持拖拽移动、快捷键、面包屑。
- 空目录可见。
- 搜索默认当前工作区，可扩成「我加入的全部工作区」；结果必须标明工作区 / 笔记本 / 目录。
- 分享、AI、导入都是动作，不抢主结构。

### 9.2 Markdown 语法闭集（一期）

只保证下面这些在编辑器、文档站、分享页、MCP 返回里渲染一致：

- 普通 Markdown + GitHub Flavored Markdown（表格、删除线、任务列表）
- 标题、列表、引用、代码块、行内代码
- 图片、链接
- `$公式$` / `$$公式$$`
- `[[wikilink]]`、`[[标题#节]]`、`[[标题|别名]]`、`![[embed]]`
- ` ```mermaid ` 图块（流程图 / 时序图 / 类图 / 状态图 / ER / 思维导图 / 甘特图）
- **Callout**：`> [!NOTE] 可选标题`（12 种类型 + GitHub 的 `IMPORTANT` / `CAUTION` 两个别名）
- **脚注**：`正文[^1]` + `[^1]: 注释`
- **`==高亮==`**

一期不做：自定义 HTML。导出到 Obsidian 时，闭集内语法应仍可读。

后加的这三样各有一条要记住的：

| 语法 | 别的工具打开会怎样 |
|---|---|
| Callout | 不认这套语法的（GitHub 只认其中 5 种）渲染成**普通引用块**，内容一个字不丢 |
| 脚注 | Obsidian、GitHub、Typora 都认，写法通行 |
| `==高亮==` | **Obsidian 私有语法**，别处会显示成字面量 `==重点==`。收它是因为中文笔记里太常用；不能接受这条局限的，用 `**粗体**` |

脚注支持的是一个子集：定义写一行，续行缩进 4 空格，内容按**行内**解析（放得下粗体、链接、双链，
放不下列表和代码块）；编号按首次引用的顺序排；引用了但没定义的原样留成 `[^x]`。

图只走代码块，没有独立的画布格式：源码仍是唯一事实源，版本 diff、`expected_version`、
导回 Obsidian 全都不受影响。渲染库按需加载，没图的笔记不下载它（设计 17 §3）。

### 9.3 附件限额

实例可改，默认：

| 项 | 默认 |
|---|---|
| 单篇笔记源文件 | 2 MB |
| 单个附件 | 20 MB |
| 单用户附件合计 | 5 GB |
| 单工作区附件合计 | 20 GB |
| 动态配图 | 最多 9 张，单张 5 MB |

粘贴或拖入图片：立刻存为当前笔记附件，正文插入相对路径。

### 9.4 双链：源码存标题，库内绑 ID

- **源文件里写** `[[会议纪要]]`、`[[会议纪要#决议]]`、`[[会议纪要|纪要]]`，保证 zip 导出能回 Obsidian。
- **库内解析表**把每次解析结果绑到笔记 UUID。改标题、移动路径时回写源码里的标题，分享 URL 因绑 ID 不变。
- frontmatter 支持 `aliases`，链到别名也算命中。
- 同目录不允许重名；跨目录允许，点开时消歧（当前本优先，再本工作区，再跨区）。
- 标题匹配内部大小写不敏感（照顾 Windows 托管）。
- `![[嵌入]]` 只展开一层，再嵌显示占位，防止循环。
- 未创建链接：点击后在当前目录生成新笔记。
- 未链接提及：一期只读提示，不自动改文。
- 图谱一期只做当前笔记局部图。

### 9.5 跨工作区搜索与双链

- 搜索：默认当前工作区；可切换「我的全部工作区」。不搜我未加入的区。
- 双链：允许指向另一工作区里自己有权看的笔记。写法仍是 `[[标题]]`；有歧义时用补全选「工作区 / 笔记本 / 标题」。
- 无权或已退出的区：渲染为「存在但不可见」，MCP 同样拒绝。
- 文档站 / 广场上的跨区链接：仅当目标已公开（已发布或有有效分享）才给访客可点的地址，否则当普通文本。

## 11. 分享与对外文档站

文档站和分享链接是两条独立通道。下线整本站 **不会** 作废已经发出的分享链接；取消某条分享也 **不会** 影响文档站。

### 11.1 文档站 = 实时投影

- 一本笔记本可「发布为站点」。导航 = 目录树；`published: false` 的当草稿隐藏。
- **源笔记保存后，公开页立刻变。** 没有「再点一次发布」的二次确认。
- 不想直播：把篇设为 `published: false`，或在未发布的本里写。
- 取消整本发布：`/s/...` 立即 404。已发出的单篇 / 目录分享链接仍按自己的密码、有效期、取消状态活着。
- 可配首页、站名、Logo、主题色。地址：`/s/{workspace}/{notebook-slug}`。
- 自定义域名二期。
- 登录且有权限时可从公开页跳回编辑。
- 对外站不提供 MCP。
- 可单独关评论、纠错、访客入口。

### 11.2 分享链接（独立生命周期）

对象可以是：单篇、单节（标题锚点）、附件、**目录（含其下已存在的子树）**。

一篇 / 一个目录可以有 **多条** 链接，互不影响，例如：一条给亲戚（有密码、7 天），一条给同事（无密码、不过期）。

每条链接可配：

| 项 | 说明 |
|---|---|
| 访问密码 | 可选 |
| 有效期 | 可选；到期立即 404 |
| 是否允许搜索引擎 | 默认否 |
| 是否显示反向链接 | 默认否 |
| 状态 | 有效 / 已取消 / 已过期 |

规则：

- 阅读页干净：无编辑器、无 AI、无工作区树。目录分享展示该目录的只读树。
- **取消分享**只作废这一条，可在管理页操作；不删源笔记。
- 轮换 = 作废旧链并生成新链。
- 源笔记进回收站：访问提示不存在；恢复后，仍有效且未到期的链接复活。
- 附件直链用不可枚举的随机 ID，避免被遍历。

### 11.3 谁能创建、谁能打开

| 动作 | 谁 |
|---|---|
| 创建单篇 / 单节 / 附件 / 目录分享 | 对该内容有编辑权的 Editor，以及 Admin / Owner |
| 发布 / 下线整本文档站 | 仅 Admin / Owner |
| 打开分享链接 | 任何持链的人（含未登录）；设了密码则须通过 |
| 管理、取消自己创建的链接 | 创建者 |
| 管理本区全部链接 | 工作区 Admin / Owner |
| Viewer | 不能创建分享 |

个人分享链接默认开评论、关纠错。

### 11.4 分享管理页

每个登录用户有「我的分享」：

- 列出自己建的全部链接：对象、密码（只显示是否已设，不回显明文）、有效期、状态、创建时间
- 取消、续期、改密码、复制链接
- 工作区 Admin / Owner 另有「本区分享」看全区

## 12. 评论与纠错

### 12.1 评论

可挂在：广场帖、圈子帖、公开文档、分享页、标题锚点。

| 作者 | 策略 |
|---|---|
| 登录用户 | 直发，作者 / 管理员仍可删或隐藏 |
| 访客 | 昵称 + 邮箱 + 验证码，待审通过后公开 |

- 一层楼中楼。纯文本或单行 Markdown。作者 5 分钟内可改，之后只能删。
- 作者、工作区 Admin、实例 Admin 可审核 / 删除 / 隐藏。

### 12.2 纠错

- 只存在于已发布文档或分享页。
- 记录原文片段、建议原文、说明、锚点。
- **所有纠错都待审**，包括登录用户。
- 接受权 = 该笔记的编辑者（不必上升到 Admin）。
- 源文已变、对不上则标「已过期」，不能硬打补丁。
- 接受 = 打补丁 + 新版本 + 文档站立刻更新。
- 拒绝 = 留理由。

## 13. 广场与工作区动态

```
Post
  scope: instance | workspace
  workspace_id: null | id
  author_id
  body_md
  attachments[]
  reply_to?
  linked_note_ids[]
```

- 广场：注册用户可发，未登录只读，按最新排序。不做关注、推荐、转发。
- 圈子：仅成员可见；Viewer 只读，Editor 及以上可发。可链私有笔记，渲染走 ACL。
- 圈子公开到广场是发布动作：未公开笔记必须警告并截断预览。
- 作者可编辑（标「已编辑」）可删。实例可关广场，工作区可关圈子。
- 实例可开内容审核：发布先过 AI，判定不通过转「待人工审核」，只有作者自己看得到，管理员复核后才公开。配置与队列见[设计 18](./设计/18-内容审核.md)。
- `/u/{handle}`：公开帖 + 已发布的文档站。
- `#标签` 一期只是搜索词。
- 动态默认不进 MCP；要单独开 `feed.*`。
- handle 全局唯一、小写；显示名可改。公开主页靠 handle。

## 14. AI

- 工作区默认模型 + embedding；可是否允许用工作区 API Key。
- 成员可自带 Key。实例和工作区都可关 AI。

| 线 | 作用域 | 落盘规则 |
|---|---|---|
| 写作 | 当前篇 / 选区 | 出 diff，人确认才写 |
| 管理 | 有权限的笔记本 | 建议标签、目录、补链；批量改要二次确认 |
| 问答 | ACL ∩ `ai_index=true` | 必须带引用 |

- 写作不留多轮。问答会话留在用户侧栏，不进知识库，除非「沉淀为笔记」。
- 索引只吃笔记正文和抽出的附件文本，不吃评论、纠错、动态（动态另授权）。
- 保存后异步重建该篇索引。
- 模型不得执行笔记里的「忽略以上指令」。
- embedding 与聊天模型分开配。支持 OpenAI 兼容、可选 Anthropic / Gemini、Ollama。

## 15. MCP：大脑接口

设计原则：标准 MCP，开源友好。不绑死某一家客户端；配置就是 URL + 头 + 钥匙，用户可复制到 Cursor、Claude Desktop 或自写客户端。

### 15.1 钥匙模型

一把钥匙绑定：**一个用户 + 一个工作区**。不能一把打穿全站。用户在多个工作区当大脑，就发多把钥匙。

在该工作区内，笔记本范围二选一：

| 模式 | 含义 |
|---|---|
| 跟随工作区权限 | 这把钥匙能碰的笔记本 = 这个人在本区已经能碰的（含之后新获得的） |
| 指定笔记本 | 白名单多选；只能是此人当前有权的本；之后新本不会自动进入 |

再叠加读写：

| 读写档 | 能力 |
|---|---|
| 只读 | list / search / get / backlinks / ask |
| 读写 | 只读 + create / update / append |
| 管理 | 读写 + move / add_tags；`delete` 仍默认关，需单独勾选 |

还可再减权：

- `require_ai_index` 默认 true
- `allow_private_notebooks` 默认 false
- 过期时间、日写入上限
- `feed.public` / `feed.workspace` 默认关

预置三档（创建时一键套用，仍可改笔记本范围）：

| 档位 | 读写 | 给谁 |
|---|---|---|
| 只读大脑 | 只读 | 公用助手 |
| 写作助手 | 读写 | 个人 Cursor / Claude |
| 管理员 | 管理，无 delete | 要自动整理的 Agent |

底线：钥匙不能大于这个人本身的 ACL。指定了某本但后来被移出该本，钥匙立刻碰不到。

### 15.2 连接与轮换（开源友好）

设置页提供：

- **一键复制** Cursor / Claude Desktop 的 MCP 配置片段（服务地址、Header、钥匙占位）
- 创建时钥匙明文 **只显示一次**
- 列表：名称、工作区、笔记本范围、读写档、最后使用时间、过期
- **轮换**：旧钥匙立即作废，发一把同权限新钥匙
- **吊销**：立即作废
- 文档公开协议：工具名、参数、错误码，方便第三方客户端接入

### 15.3 一期工具

读：`get_me`、`list_notebooks`、`list_folder`、`search_notes`、`get_note`、`get_backlinks`、`ask_knowledge`

写：`create_note`、`update_note`（必须 `expected_version`）、`append_to_note`、`move_note`、`add_tags`

- `get_me`：返回当前用户、工作区、笔记本范围、读写档，方便 Agent 自检。
- `create_note` 的 `ai_index` / `published` 跟随目标笔记本默认值。
- `search_notes` 必须有条数上限和摘要，禁止一次拉走整库正文。

每次写入：鉴权 → 工作区绑定 → ACL → 笔记本范围 → `ai_index` 约束 → 落盘 → 审计（谁、哪把钥匙、改前快照）。

## 16. 备份

主存储在服务器磁盘。S3 / WebDAV 是逃生舱。

分两层：

| 层 | 谁配 | 内容 |
|---|---|---|
| 实例备份 | 实例管理员 | 用户、注册策略与注册码元数据、广场、全局配置 |
| 工作区备份 | Owner / Admin | 该区 Markdown、附件、ACL、圈子、文档站、分享链接元数据、评论纠错、版本、回收站 |

- 可整库回滚，可按路径捞单篇。

## 19. 一期范围

### 19.1 P0

1. 第一人注册为实例管理员；注册策略 + 邮箱验证 + 注册码
2. 个人工作区（不可邀请）+ 自建工作区 + 邀请已有用户 + 成员 / 笔记本 ACL
3. Markdown 闭集三栏 + 双链（源码标题 / 库内 ID）+ 跨区搜索 / 双链 + 导入 md / zip
4. 附件限额；回收站
5. 单篇 / 单节 / 目录分享（多链接、密码、有效期、管理页）+ 整本文档站（实时投影，生命周期独立）
6. 可配 AI + `ai_index` 本级默认 / 单篇覆盖
7. MCP：单区绑定、多笔记本或跟随工作区权限、读写档、`get_me`、配置复制、轮换 / 吊销、审计
8. S3 / WebDAV 双层备份
9. 移出成员 / 封禁 / 注销

### 19.2 P1

10. 广场与工作区动态
11. 文档站评论 + 纠错队列
12. 动态 ⇄ 笔记 转正 / 摘发

### 19.3 一期明确不做

- 块编辑器、数据库、看板、画布
- 全局知识图谱、关注 / 推荐 / 转发
- 自定义域名、SSO、LDAP、2FA
- Agent 定时自动整理全库
- 移动端 App
- S3 作主附件盘
- Callout / 脚注 / docx / 语雀 / Notion / 微信导入
- 鼠标拖拽画图（白板 / draw.io 那种自由画布）

原来列在这里的「实时多人光标」已改为**要做**：见 [设计 17 §3.4](设计/17-编辑器方案.md)。
CRDT 只做在线这一层，落库仍然回 `notes.body_md` + `note_versions`，
所以 03 定的版本模型、MCP 与 AI 的写入路径一个字都不用改。

一期结束时应能发生：

- 空库第一个注册的人成为管理员，再发注册码把家人拉进来
- 家里有人有私密本，有人有共享本；孩子看不到账本；普通笔记默认允许 AI 读，账本把本级开关关掉后不再进大脑
- 跨工作区能搜、能链；一把 MCP 钥匙只活在一个工作区，本子可多选或跟随权限，读写分开
- 一篇可以发出去两条不同密码和有效期的链接，管理页能取消；下线文档站不影响这些链接
- 改名不碎链；源码仍是 `[[标题]]`
- Cursor 用开源标准 MCP 配置连上；轮换钥匙后旧配置立刻失效
- 误删进回收站；封禁、注销不拆掉别人还在用的共享知识
- 每天备份能恢复，备份里没有钥匙明文

## 20. 关键用户故事

1. **第一人**：空站第一个注册成功的用户进入实例后台；之后注册的人没有。
2. **私人账本**：父母把「账本」的 `default_ai_index` 改成关，本内新笔记默认不进大脑；该本同时设为个人私有，孩子同区看不到。未改过的普通本仍默认允许 AI 读。把账本里一篇临时打开 `ai_index` 后，只有有权的人的钥匙能问到这一篇。
3. **注册码进组**：管理员批量生成一次性码，绑定「家庭」+ Editor。新用户持码注册后进入家庭区，并拥有不可邀请他人的个人工作区。
4. **已有用户邀请**：已在站内的亲戚通过邀请链接加入家庭区，不必再注册。
5. **双链不碎**：改名并移动后，其它笔记里的 `[[旧标题]]` 被回写成新标题，仍指向同一 UUID，分享 URL 不变。
6. **跨区链接**：在「工作室」笔记里 `[[家庭食谱]]`，补全选中家庭区那篇；没加入家庭区的同事只看到「存在但不可见」。
7. **无权侧信道**：链到他人私密日记，预览和 MCP `get_note` 都被拒。
8. **多条分享**：同一篇食谱两条链接，一条有密码 7 天，一条无密码不过期；取消第一条不影响第二条。
9. **目录分享**：把「食谱 / 家常」目录做成只读树发出去；目录里后来新增的篇是否出现——一期按实时投影，新增即可见（与文档站一致）。若目录进回收站，链接失效。
10. **站与链独立**：下线「家庭Wiki」文档站后 `/s/...` 404，但该本里已发出的单篇分享仍可在有效期内打开。
11. **我的分享**：用户在 `/shares` 改密码、续期、取消；Admin 能看到本区全部链接。
12. **访客纠错**：未登录提交错字进待审；有编辑权的人接受后源笔记出新版本，文档站立刻变。
13. **登录回库**：未登录看广场；登录进个人工作区。
14. **MCP 范围**：张三在「工作」区发一把读写钥匙，指定「项目A + 项目B」。Agent 读「项目C」或写「家庭」区都被拒并记审计。后来张三被移出项目 B，这把钥匙立刻失去 B。
15. **跟随权限**：李四发一把「跟随工作区权限」的只读钥匙；被加进新笔记本后，不必换钥匙就能搜到新本（仍受 `ai_index` 约束）。
16. **钥匙轮换**：轮换后旧 Cursor 配置失效；设置页可再复制新配置。
17. **回收站**：误删「会议纪要」，反向链接显示已删除；从回收站恢复后链接活过来，未取消的分享也活过来。
18. **移出成员**：把孩子从「家庭」移出，其私有日记迁回个人工作区；家庭菜谱留下。
19. **封禁**：捣乱用户被封后不能登录，广场帖隐藏，他写过的家庭共享笔记还在。
20. **注销**：用户先把「读书会」Owner 转给别人才能注销；个人库销毁，文档站下他的评论变成「已注销用户」。
21. **备份恢复**：从 WebDAV / S3 恢复后权限、分享、回收站还在；备份包里没有 MCP 钥匙明文。

## 21. 权限速查

| 动作 | 访客 | 登录用户 | 本区 Viewer | 本区 Editor | 本区 Admin / Owner | 实例管理员 |
|---|---|---|---|---|---|---|
| 看广场 | 是 | 是 | 是 | 是 | 是 | 是 |
