# 主题开发手册

面向想给本实例换皮、或做一套主题分享给家人的人。  
产品规则见 [15-主题系统](./设计/15-主题系统.md)。出厂皮肤是 **现代墨白**（`mono-modern`）。

一期主题 = 一份 `theme.json`（浅色 + 深色 token）。不支持主题里写 JavaScript，也不支持外链 CSS / 外链字体。

---

## 1. 两分钟理解

换外观有两层，不要混：

| 层 | 谁改 | 改什么 | 要不要做包 |
|---|---|---|---|
| 主题色 accent | 每个用户设置里点一下 | 选中条、主按钮、双链 | 不必 |
| 主题包 | 导入一份 json/zip | 底色、文字、边线、圆角、字体栈、整套气质 | 要 |

用户启用你的包之后，**仍可以再调自己的主题色**。你的 `accent` 只是默认值。

明暗由用户选「跟随系统 / 浅 / 深」，所以 **light 和 dark 必须都写满**，系统不会帮你自动反相。

---

## 2. 十分钟做一个主题

1. 新建文件夹，名字用英文短横线，例如 `paper-ink`。
2. 在里面放 `theme.json`（下面有完整模板）。
3. 改 `id`（全局唯一，只能小写字母数字和 `-`）、`name`、两套颜色。
4. 把文件夹打成 zip（里面直接是 `theme.json`，或只有一层目录）。
5. 登录后打开 **设置 → 外观 → 导入主题**，选这个 zip。
6. 点「启用」。也可把未打包的目录拷到服务器 `DATA_DIR/themes/paper-ink/`，刷新主题列表。

`id` 不要和已安装的撞。出厂占用：`mono-modern`。

---

## 3. theme.json 规范

### 3.1 根字段

| 字段 | 必填 | 规则 |
|---|---|---|
| `id` | 是 | `^[a-z][a-z0-9-]{1,63}$` |
| `name` | 是 | 1–40 字，设置页显示 |
| `version` | 是 | semver，如 `1.0.0`。同 id 再导入且版本更新 = 升级 |
| `author` | 否 | 显示用 |
| `description` | 否 | ≤ 200 字 |
| `homepage` | 否 | 只展示，不会去拉资源 |
| `modes` | 是 | 必须是 `["light","dark"]` |
| `navActiveStyle` | 否 | `solid`（黑底反白，出厂默认）或 `soft`（浅底） |
| `tokens.light` | 是 | 见下表 |
| `tokens.dark` | 是 | 同上，一套都不能少 |

### 3.2 tokens 必填键

颜色一律 `#RGB` 或 `#RRGGBB`（大小写均可）。不要 `rgb()`、不要 `oklch`、不要 CSS 变量套变量。

| 键 | 用在哪 |
|---|---|
| `bg` | 页面、编辑器底 |
| `bg-subtle` | 左栏、顶栏次底 |
| `bg-muted` | 源码栏、输入框底 |
| `fg` | 主文字 |
| `fg-muted` | 次要文字、时间、提示 |
| `border` | 分割线、输入框边 |
| `accent` | 主题色默认（用户可覆盖） |
| `good` | 成功、已保存 |
| `danger` | 错误、删除 |
| `warning` | 冲突、过期 |
| `radius` | 如 `"8px"`，只允许 `px` / `rem` 数字 |
| `font-ui` | 界面字体栈 |
| `font-mono` | 代码 / Markdown 源码 |
| `font-title` | 大标题，可与 ui 相同 |

可选键（不写则按 accent 派生或与 accent 相同）：

| 键 | 默认 |
|---|---|
| `accent-fg` | 按 accent 亮度自动黑或白 |
| `accent-soft` | accent 与 bg 混合约 12% |
| `wiki` | 同 accent |
| `wiki-unresolved` | 同 fg-muted |

禁止出现未列出的键（一期会警告并忽略，以免以后语义冲突）。

### 3.3 完整模板（从出厂复制再改）

  "modes": ["light", "dark"],
  "navActiveStyle": "solid",
  "tokens": {
    "light": {

      "bg-subtle": "#F4F4F5",
      "bg-muted": "#ECECEE",

    },

      "bg": "#0A0A0A",

      "bg-muted": "#1A1A1A",

## 4. 怎么配才好看、且过得了校验

- **先定 bg / fg / border，最后再动 accent。** 现代墨白的活力来自对比，不是来自花色。
- 正文对比：`fg` 相对 `bg` 建议 ≥ 7:1，硬性 ≥ 4.5:1。不够会装上但设置页打警告。
- 不要用纯 `#FFFFFF` 配纯 `#000000` 且中间没有 `bg-subtle`：三栏会糊成一块。
- `fg-muted` 不要太浅（浅色模式别高于大约 `#8A8A8A`），时间戳会看不清。
- 浅色 `accent` 若接近白，实心选中条会看不出；改用 `navActiveStyle: "soft"`，或把 accent 加深。
- 字体栈只写系统里有的。中文至少留 `"PingFang SC", "Microsoft YaHei", sans-serif`。
- **禁止** `url(https://fonts.google.com/...)`。自定义字体文件是二期。

对比度自测（近似）：

```
L = 相对亮度（sRGB）
contrast = (L浅 + 0.05) / (L深 + 0.05)
```

导入时服务器会算一遍 `fg` vs `bg`、`accent-fg` vs `accent`。

## 5. 安装、升级、卸载

| 动作 | 结果 |
|---|---|
| 导入新 id | 安装，可立即启用 |
| 导入已有 id 且 version 更新 | 升级，正在用的人下次刷新拿到新 token |
| 导入已有 id 且 version 相同或更旧 | 拒绝，避免误覆盖 |
| 卸载 | `mono-modern` 不能卸；别人正在用则回退出厂并通知 |
| 包坏了 | 回退出厂，界面永远能亮 |

管理员可关「允许成员自己装主题」，那时只有实例后台能导入，成员只能选已经装上的。

---

## 6. 主题作用范围

| 页面 | 用谁的主题 |
|---|---|
| 登录后的三栏 / 设置 / 圈子 | 当前用户 |
| 未登录广场、登录页、分享页 | 实例默认主题 + 实例默认 accent |
| 文档站 `/s/...` | 该笔记本指定，否则实例默认 |
| 点「编辑原文」回到 App | 又变回用户自己的主题 |

不要在主题里假设「全世界都是深色」——公开页可能是浅色实例默认。

---

## 7. 会被拒绝的包

- 缺 `id` / `name` / `version` / 任一 mode 的必填 token
- `id` 非法或为 `mono-modern`（不能覆盖出厂 id，只能用设置里的「从当前导出」另存）
- 颜色不是 hex
- `radius` 不是合法长度
- json 以外还塞了 `.js` / `.html` / `.exe`（zip 里只允许 `theme.json`、`preview.png`、`README.md`）
- 文件总大小 > 256 KB（一期无图片也可；有 `preview.png` 时预览图 ≤ 200 KB）

---

## 8. 从当前外观导出

设置 → 外观 → **导出当前**：把「正在用的主题 token + 你的 accent」打成新包。  
适合：先在设置里调好主题色，再固化成可分享的主题。导出时会要求你填一个新 `id`。

---

## 9. 给作者的检查清单

- [ ] light / dark 两套键完全一致  
- [ ] 三栏里能分清左栏、中栏、编辑器  
- [ ] 实心选中（solid）时字是 `accent-fg`，能看清  
- [ ] 未解析双链（虚线）和普通字能区分  
- [ ] 文档站长文读得下去，不只是设置页好看  
- [ ] 没写 JS、没外链  

做完把 zip 发给实例管理员即可，不需要发版到任何商店。
