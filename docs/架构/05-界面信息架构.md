# 05 界面信息架构

前端：React 19 + TypeScript + Vite，路由 React Router 7；样式与组件采用 Tailwind CSS + shadcn/ui + Radix UI。公开页与登录后 App 使用独立壳，不要把三栏编辑器套在广场上。组件与视觉约束见 [14-UI规范与方案](../设计/14-UI规范与方案.md)。

## 2. 四套壳

### 2.1 Public

顶栏：实例名、登录/注册。已登录多一个「我的库」。  
主栏：动态 / 笔记本 / 文章分段；动态顶上搜索框。  
无左树、无 AI。

### 2.2 Site / Share

极简阅读：站名、目录（仅 Site 或目录分享）、正文、评论。  
已登录且 can_edit：右上「编辑原文」进 `/w/.../n/:id`。  
无工作区切换。

### 2.3 App

```
顶栏：工作区切换 | 笔记 / 项目 / 广场 / 圈子 / 导航（有新动态或新回复时带数字） | 搜索 Ctrl+K | 铃铛 | 头像
左：笔记本列表（含「已分享 / 日历 / 今天」一级入口）
中：当前本目录树 —— 进已分享时中栏换成收到列表或该通道只读树；进日历时换成日历网格；左树不重排
右：编辑器 —— 进已分享时换成只读正文；进日历时换成任务面板（收件箱 + 按笔记分组）
抽屉：反向链接 / 版本 / AI 写作 / AI 画图（Tab）
```

窄屏：树可折叠，不在一期做独立移动 App。

### 2.4 Settings

配置类页面（工作区设置、回收站、AI 与 MCP、外观）共用 `components/settings-shell.tsx`：
顶栏面包屑 + 左栏分组导航 + 主栏卡片。回收站和 AI 与 MCP 是导航里的一等条目，
从设置点进去不换壳、不丢面包屑。视觉与三态规范见 [14-UI规范与方案 §14.1](../设计/14-UI规范与方案.md)。

## 3. 关键页面状态

### 3.1 编辑器

- 加载：骨架。
- 只读（Viewer / frozen）：隐藏保存与开关写。
- dirty / saving / saved / conflict：底栏。conflict 双按钮「加载对方 / 强制覆盖」。
- 顶芯片：已发布、AI 可读、分享 n 条。点开面板。
- 无人时空状态：本内「写第一篇」。

### 3.2 Ctrl+K

输入即搜当前区；Tab 切「全部工作区」。结果展示 `区/本/路径`。空输入：最近与收藏。

### 3.3 分享创建

模态：类型、密码、有效期、生成、复制。关闭后仍可在 `/shares` 复制（靠 token_enc）。  
入口：笔记顶栏「分享」；笔记本左栏右键或中栏本操作「分享这个笔记本」。整本与单篇共用同一套弹窗。

### 3.4 MCP 创建

模态步进：区 → 档位 → inherit/勾选本 → 高级。结果页大字密文 + 两个复制配置按钮 + 「我已写下」。关闭不可再看密文。

### 3.5 待审

`/w/:id/settings/inbox`：评论 / 纠错两个队列。纠错并排原文与建议。

### 3.6 管理

`/admin` 侧栏：概览、注册、注册码、用户、服务申请、SMTP、广场、主题、导航、智能体、实例备份（WebDAV / S3）。零用户不必进这里（还没账号）。用户行要看得出用量和待审批；点开能直接改配额。

导航页 `/nav`：问候 + 搜索 + 左轨分组 + 站点卡片。空目录给管理员「去配置」。视觉约束见设计 19 与 [14](../设计/14-UI规范与方案.md)。

外观页：色板 + hex、主题卡片、导入 zip。改色即时预览小三栏。

## 4. 权限与菜单显隐

前端用 `/me` + membership 藏按钮，**所有写仍以服务端为准**。  
个人工作区：邀请按钮 disabled + 说明。  
Viewer：无新建、无分享、无 MCP 写档入口。  
实例管理员进他人工作区：不出现「我能看私密本」的假入口。

## 5. 渲染一致性

`packages/shared/markdown` 一套解析：

- App 预览
- Site / Share
- 广场帖（公开双链规则不同，走 render 参数 `mode: library | public`）
- 问知识库回答

禁止站点再引一套 React Markdown 默认插件导致 wikilink 行为漂移。
