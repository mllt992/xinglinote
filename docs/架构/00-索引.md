## 分层对照

```
界面 05  ──HTTP/Cookie──►  API 进程 03
客户端 MCP ──Bearer──►  同一 API 进程 /mcp
                         │
                         ├─ 领域服务（复用设计 02 的 ACL 函数）
                         ├─ 发事件 ──► 队列 04 ──► worker
                         ├─ PostgreSQL 02
                         └─ 本地文件 01
```

禁止：前端直连数据库、MCP 另写一套保存/ACL、Worker 绕过领域服务改笔记正文。
